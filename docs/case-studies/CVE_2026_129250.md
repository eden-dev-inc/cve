# Edimax BR6478ACV2: buffer overflow in formPPTPSetup (CVE-2026-129250)

A remote attacker can send an oversized PPTP username to the vulnerable Edimax setup handler. The resulting buffer overflow can disrupt the device or allow code execution.

**Patch title.** Edimax BR6478ACV2 PPTP Username Guard (`edimax-br6478acv2-pptp-username-guard` in the registry). ## The vulnerability

The affected versions and upgrade guidance are listed above. The Eden policy and module were tested against the HTTP fixture described below.

## Synthetic HTTP controls

**Tier 1 — declarative policy.** The recorded policy denies every method on the recorded fixture route and its descendants. This is a coarse rule: it also blocked the benign probe on the same route, which is the recorded false positive.

```json
{
  "version": 1,
  "profile": "http-structure-v1",
  "policy": {
    "version": 1,
    "rules": [
      {
        "scope": {
          "methods": [],
          "path": "/goform/formPPTPSetup",
          "descendants": true
        },
        "require": {
          "kind": "deny"
        }
      }
    ]
  }
}
```

**Tier 2 — native Rust module.** The rule refuses matching requests containing a raw PPTP username value longer than 256 bytes in the target or body.

```rust
const ROUTE: &[u8] = b"/goform/formPPTPSetup";
```

## Fixture and probes

The ordinary probe used a short PPTP username. The marked request used a 300-byte username and the fixture counted its delivery.

## Signed module authority

Read-only inspection was refused (403) for the reader principal, admission of a tampered statement was rejected (400), and admission of an invalid signature was refused (403).
