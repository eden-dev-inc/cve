# Switchvox: unauthenticated SQL injection to RCE via the /pa endpoint (CVE-2026-9586)

Switchvox SMB Edition has a SQL injection flaw in its /pa endpoint letting an attacker run arbitrary SQL statements against the backend PostgreSQL database — database operations through remote code execution — remotely, without logging in, in a single crafted request. CISA lists the flaw as exploited in attacks.

## The vulnerability

The /pa endpoint interpolates unauthenticated parameters into SQL, so a crafted value reads or writes the PBX database and reaches code execution. Eden fronts the Switchvox web interface, so the injected request rides an HTTP request Eden can refuse before release.

## The Eden patch

**Tier 1 — declarative policy.** The recorded policy denies every method on the recorded fixture route and its descendants. This is a coarse rule: it also blocked the benign probe on the same route, which is the recorded false positive.

```json
{
  "version": 1,
  "profile": "http-structure-v1",
  "policy": {
    "version": 1,
    "rules": [
      {
        "scope": {
          "methods": [],
          "path": "/pa",
          "descendants": true
        },
        "require": {
          "kind": "deny"
        }
      }
    ]
  }
}
```

**Tier 2 — native Rust module.** gabriel_swxpa_v1 waits for a complete request, matches the /pa endpoint exactly, and refuses targets or bodies carrying SQL injection markers (' OR, union select, 1=1, '--). Clean requests continue.

```rust
static NEEDLES: [&[u8]; 4] = [b"' or", b"union select", b"1=1", b"'--"];
```

## Implement the remediation

The commands are operator examples for the recorded scope. Compare fixture routes and software selectors with the intended deployment before use. See [deployment prerequisites](../deployment.md) and the [API example](../../cve/CVE-2026-9586/http-request-filter/api.md).

1. **Prepare the target.** Verify the loaded Sangoma Switchvox SMB Edition version against the advisory. Use a compatible Eden HTTP interlay and an authenticated operator with Configure permission. Use the recorded declaration and the linked source.
2. **Apply the declaratory policy.** Set `INTERLAY` to the target interlay UUID in the authenticated Eden CLI. Save the interlay's complete current settings, place the policy from this report in `settings.remediation`, and PATCH the full settings object with a fresh `Idempotency-Key`. Read the interlay back and confirm `remediation_status.state` is `ready`.
3. **Import and activate the native module.** Build the schema-2 archive from the linked source with the compatible SDK, verify its digest, and PUT it to the interlay's patch-packages endpoint. Import requires explicit activation: enroll the publisher key, attest the host inventory, inspect the returned configuration, obtain independent host approval, sign the typed statement, admit, and activate. Read the receipt until `serving_now` is true and the expected shards are acknowledged. Full command sequences are in the [API example](../../cve/CVE-2026-9586/http-request-filter/api.md).
4. **Verify, revoke, and restore.** Replay the benign and advisory-shaped probes and compare the backend counter. Revoke the operation and confirm the advisory-shaped request no longer succeeds (fail-closed 503); re-approve, re-admit, and reactivate a replacement operation to restore protection.

**Vendor update.** The fixed release carries the durable repair; the [advisory](https://cve.now/CVE-2026-9586) links the vendor's update instructions where available. Eden's tiers are an enforcement stopgap for a deployment that cannot upgrade immediately.

## Fixture and probes

The benign probe issued a clean status query. The advisory-shaped probe carried a SQL predicate in the same parameter. The fixture incremented its marker when injected SQL reached its database engine.

## Signed module authority

Import returned HTTP 201 with explicit activation required and signature verification deferred. Read-only inspection was refused (403) for the reader principal, admission of a tampered statement was rejected (400), and admission of an invalid signature was refused (403). After revocation the advisory-shaped probe received HTTP 503 (fail-closed); re-approval and reactivation restored the refusal (403, counter unchanged).
