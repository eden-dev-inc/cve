# PAN-OS: management interface root code execution (CVE-2026-0322)

Palo Alto PAN-OS, on PA-Series and VM-Series firewalls and Panorama, lets a logged-in attacker run arbitrary code with root privileges through the management interface. The attacker needs network reachability and high-privilege login access — and the flaw is being exploited in attacks, per CISA KEV. A root shell on a perimeter firewall is total control of the enforcement boundary.

## The vulnerability

The management interface passes crafted values into privileged execution with root privileges, so an authenticated administrator escalates to full device code execution. Eden fronts the management interface, so the crafted request rides an HTTP request Eden can refuse before release.

## The Eden patch

**Tier 1 — declarative policy.** The recorded policy denies every method on the recorded fixture route and its descendants. This is a coarse rule: it also blocked the benign probe on the same route, which is the recorded false positive.

```json
{
  "version": 1,
  "profile": "http-structure-v1",
  "policy": {
    "version": 1,
    "rules": [
      {
        "scope": {
          "methods": [],
          "path": "/api",
          "descendants": true
        },
        "require": {
          "kind": "deny"
        }
      }
    ]
  }
}
```

**Tier 2 — native Rust module.** gabriel_panosrce_v1 waits for a complete request, matches management API routes, and refuses bodies carrying shell metacharacter markers (;, $(, backtick) — the command-injection shapes that reach the vulnerable management execution.

```rust
const ROUTE: &[u8] = b"/api";
static MARKS: [&[u8]; 3] = [b";", b"$(", b"`"];
```

## Implement the remediation

The commands are operator examples for the recorded scope. Compare fixture routes and software selectors with the intended deployment before use. See [deployment prerequisites](../deployment.md) and the [API example](../../cve/CVE-2026-0322/http-request-filter/api.md).

1. **Prepare the target.** Verify the loaded Palo Alto PAN-OS version against the advisory. Use a compatible Eden HTTP interlay and an authenticated operator with Configure permission. Use the recorded declaration and the linked source.
2. **Apply the declaratory policy.** Set `INTERLAY` to the target interlay UUID in the authenticated Eden CLI. Save the interlay's complete current settings, place the policy from this report in `settings.remediation`, and PATCH the full settings object with a fresh `Idempotency-Key`. Read the interlay back and confirm `remediation_status.state` is `ready`.
3. **Import and activate the native module.** Build the schema-2 archive from the linked source with the compatible SDK, verify its digest, and PUT it to the interlay's patch-packages endpoint. Import requires explicit activation: enroll the publisher key, attest the host inventory, inspect the returned configuration, obtain independent host approval, sign the typed statement, admit, and activate. Read the receipt until `serving_now` is true and the expected shards are acknowledged. Full command sequences are in the [API example](../../cve/CVE-2026-0322/http-request-filter/api.md).
4. **Verify, revoke, and restore.** Replay the benign and advisory-shaped probes and compare the backend counter. Revoke the operation and confirm the advisory-shaped request no longer succeeds (fail-closed 503); re-approve, re-admit, and reactivate a replacement operation to restore protection.

**Vendor update.** The fixed release carries the durable repair; the [advisory](https://cve.now/CVE-2026-0322) links the vendor's update instructions where available. Eden's tiers are an enforcement stopgap for a deployment that cannot upgrade immediately.

## Fixture and probes

The benign probe posted an ordinary configuration change. The advisory-shaped probe appended a metacharacter command to the same field. The fixture incremented its marker when injected commands reached the privileged handler.

The rule covers the recorded metacharacter markers on the management API; the vendor's exact vulnerable command path is internal, so the fixture delivers the injection shape honestly. The real-world path is an authenticated high-privilege admin — the recorded risk is privilege escalation to root.
