# RepoManager GPG Delete Injection (CVE-2026-130160)

An authenticated (or, for the Paymenter case, unauthenticated) remote caller can submit the vendor-documented crafted parameter to a repomanager 5.13.2 deployment and reach command execution or arbitrary file read. Update to the vendor's fixed release.

**Result.** The vendor-documented attack shape reached the fixture's simulated sink on every attack probe in the baseline, and the native module refused each one with HTTP 403 before release — no crafted parameter reached the sink while the module served — while every benign probe kept HTTP 200, including the same-route other-action controls that must keep passing. After revocation the interlay failed closed rather than silently re-exposing the route, and a replacement operation restored the refusal.

## The vulnerability

RepoManager through 5.13.2 routes its AJAX controller (`POST /ajax/controller.php`) to
`controllers/ajax/<controller>.php` by the caller-supplied `controller` and `action`
POST parameters. The `repo/source/source` controller's `delete-gpgkey` action
passes each caller-supplied `id[]` value through `Validate::string()` — which only
HTML-escapes (`htmlspecialchars(stripslashes(trim()))`) — straight into a
`gpg --delete-key` shell command line (`controllers/Gpg.php`), so any
authenticated (logged-in) user can inject shell metacharacters (the vendor PoC:
`id[]=AAAA; touch /tmp/pwned`) and execute arbitrary OS commands as the web
user. Fixed in 5.13.3, which escapes the ids at the command layer.

## The Eden patch

**Tier 1 — declarative policy.** The recorded policy denies `POST` on the `/ajax/controller.php` route family. This is a coarse rule: it also blocks the benign probes on the same route (recorded false positives).

```json
{
  "version": 1,
  "profile": "http-structure-v1",
  "policy": {
    "version": 1,
    "rules": [
      {
        "scope": {
          "methods": [
            "POST"
          ],
          "path": "/ajax/controller.php",
          "descendants": true
        },
        "require": {
          "kind": "deny"
        }
      }
    ]
  }
}
```

**Tier 2 — native Rust module.** Refuse delete-gpgkey `id[]` values carrying shell metacharacters (statement separators, substitution, pipes, redirects). Detection is scoped to the vendor-documented vulnerable controller/action pair (the `controller=`/`action=` gates), so other actions on the same route keep passing — verified by the same-route control probes.

```rust
shell_meta(b: u8) -> bool {
    matches!(b, b';' | b'&' | b'|' | b'<' | b'>' | b'`' | b'\n' | b'\r' | b'\x00')
}

/// Percent-decode one escape at raw[i]; returns (byte, next_index).
fn decode_at(raw: &[u8], i: usize) -> (u8, usize) {
    if raw[i] == b'%' && i + 2 < raw.len() && is_hex(raw[i + 1]) && is_hex(raw[i + 2]) {
        ((hex_val(raw[i + 1]) << 4) | hex_val(raw[i + 2]), i + 3)
    } else {
        (raw[i], i + 1)
    }
}

/// Percent-decode a form value into a fixed buffer (truncate on overflow).
fn decoded(value: &[u8], out: &mut [u8]) -> usize {
    let mut n = 0usize;
    let mut i = 0usize;
    while i < value.len() && n < out.len() {
        let (b, ni) = decode_at(value, i);
        out[n] = b;
        n += 1;
        i = ni;
    }
    n
}

fn value_is_attack(raw: &[u8]) -> bool {
    let mut buf = [0u8; 256];
    let n = decoded(raw, &mut buf);
    let mut i = 0usize;
    let mut prev = 0u8;
    while i < n {
        let b = buf[i];
        if shell_meta(b) {
            return true;
        }
        // command substitution `$(` — the `$` alone is not metachar (env vars
        // are harmless without exec), but `$(...)` and backticks are
        if b == b'$' && i + 1 < n && buf[i + 1] == b'(' {
            return true;
        }
        prev = b;
        i += 1;
    }
    let _ = prev;
    false
}

/// Find the raw (urlencoded) value bytes of a form key in a urlencoded
/// body/query, starting the scan at `from`. Returns (start, end) of the
/// value slice. Advances the cursor past the terminating `&`.
fn find_value(src: &[u8], key: &[u8], from: usize) -> Option<(usize, usize)> {
    let n = src.len();
    let mut i = from;
    while i + key.len() <= n {
        let edge = i == 0 || src[i - 1] == b'&' || src[i - 1] == b'?';
        let eq = edge && {
            let mut m = true;
            for (j, kb) in key.iter().enumerate() {
                if lower(src[i + j]) != lower(*kb) {
                    m = false;
                    break;
                }
            }
            m
        };
        if eq {
            let start = i + key.len();
            let mut end = start;
            while end < n && src[end] != b'&' && src[end] != b' '
                && src[end] != b'\r' && src[end] != b'\n' {
                end += 1;
            }
            return Some((start, end));
        }
        i += 1;
    }
    None
}

fn request_is_attack(head: &[u8], body: &[u8]) -> bool {
    // The request line: METHOD /ajax/controller.php?... HTTP/x
    let line_end = head.iter().position(|&b| b == b'\r').unwrap_or(head.len());
    let reqline = &head[..line_end];
    let sp = reqline.iter().position(|&b| b == b' ').unwrap_or(0);
    if !starts_with_ci(&reqline[sp + 1..], ROUTE) {
        return false;
    }
    // controller + action gates: decode each raw value into a local
    // buffer (borrow-free) and compare case-insensitively
    if !form_value_equals(head, b"controller=", CONTROLLER)
        && !form_value_equals(body, b"controller=", CONTROLLER) {
        return false;
    }
    if !form_value_equals(head, b"action=", ACTION)
        && !form_value_equals(body, b"action=", ACTION) {
        return false;
    }
    // every id[] value must be a benign key id (three spellings of the key)
    let mut from = 0usize;
    loop {
        let hit = find_value(body, b"id%5B%5D=", from)
            .or_else(|| find_value(body, b"id%5b%5d=", from))
            .or_else(|| find_value_literal(body, b"id[]=", from));
        match hit {
            Some((s, e)) => {
                if value_is_attack(&body[s..e]) {
                    return true;
                }
                from = e + 1;
            }
            None => return false,
        }
    }
}

fn find_value_literal(src: &[u8], key: &[u8], from: usize) -> Option<(usize, usize)> {
    let n = src.len();
    let mut i = from;
    while i + key.len() <= n {
        let edge = i == 0 || src[i - 1] == b'&' || src[i - 1] == b'?';
        if edge && &src[i..i + key.len()] == key {
            let start = i + key.len();
            let mut end = start;
            while end < n && src[end] != b'&' && src[end] != b' '
                && src[end] != b'\r' && src[end] != b'\n' {
                end += 1;
            }
            return Some((start, end));
        }
        i += 1;
    }
    None
}

/// Percent-decode one form value (in a local buffer) and compare it
/// case-insensitively against the expected value. Borrow-free by design.
fn form_value_equals(src: &[u8], key: &[u8], expect: &[u8]) -> bool {
    match find_value(src, key, 0) {
        Some((s, e)) => {
            let mut buf = [0u8; 64];
            let n = decoded(&src[s..e], &mut buf);
            eq_ci(&buf[..n], expect)
        }
        None => false,
    }
}

fn eq_ci(a: &[u8], b: &[u8]) -> bool {
    if a.len() != b.len() { return false; }
    a.iter().zip(b).all(|(x, y)| lower(*x) == lower(*y))
}
```

**Stated limits.** the `id[]` charset is restricted to what a GPG key id legitimately carries; a deployment whose ids carry other punctuation must adjust the condition scope. Durable fix: RepoManager 5.13.3.

## Fixture and probes

The fixture mirrors the vendor-documented request shapes (source references cited above); its oracle records a `130160-injected` effect when the crafted parameter reaches the sink on the vulnerable action.

| Probe | Shape | Baseline | Tier 1 | Tier 2 (module) |
| --- | --- | --- | --- | --- |
| benign_delete | `controller=repo/source/source&action=delete-gpgkey&id%5B%5D=ABC123DEF` | 200, clean command | 403 | 200, clean command |
| benign_multi_ids | two well-formed ids | 200, clean command | 403 | 200, clean command |
| attack_semicolon | `id%5B%5D=AAAA%3B+touch+%2Ftmp%2Fpwned` (vendor PoC) | 200, **command grammar changed** | 403 | 403, refused |
| attack_backtick | `id%5B%5D=AAAA%60touch+%2Ftmp%2Fx%60` | 200, **backtick substitution** | 403 | 403, refused |
| attack_substitution | `id%5B%5D=%24%28touch+%2Ftmp%2Fx%29` | 200, **$( ) substitution** | 403 | 403, refused |
| benign_other_action | `action=get` with a `;`-carrying id (outside the vulnerable action) | 200, id unused by this action | 403 | 200, id unused |

## Signed module authority

Import returned HTTP 201 with explicit activation required and signature verification deferred. Read-only inspection was refused (403) for the reader principal, admission of a tampered statement was rejected (400), and admission of an invalid signature was refused (403). The activation receipt reported the module serving on all 32 expected shards. After revocation the marked probe received HTTP 503 (fail-closed); re-approval and reactivation restored the refusal.
