# Apache FOP: unsafe deserialization in hyphenation loading (CVE-2026-71395)

[Source and API bundle](../../cve/CVE-2026-71395/README.md)

*[cve.now](https://cve.now/CVE-2026-71395) entry. Product: Apache XML Graphics
FOP (org.apache.xmlgraphics:fop-core) (lab: `gabriel-fop-app`).*

Eden terminates the HTTP connection to the affected product, evaluates a
declarative policy and — in tier 2 — a separately compiled native Rust module
under signed module authority, before any byte reaches the application. It does
**not** patch the affected component; the vendor's fixed release remains the
durable repair.

**Status: Remediated (tier 1 + tier 2), live-proven 2026-11-11T17:09:14Z on the
installed `eden-product-release:1.103.0` lab container.**

## The vulnerability

FOP's hyphenation-pattern loader deserializes a caller-supplied serialized
object, so a crafted FO document reaches `ObjectInputStream`-equivalent
gadget territory. The fixture (`make_fop`, port 18317) reproduces the delivery
shape: a render upload carrying the Java serialization magic marker
(`aced0005`) records a deserialization mark.

## The Eden patch

**Tier 1 — declarative policy (blunt, fail-closed):** deny every request under
`/fop`, ordinary FO rendering included — false positives measured below.

**Tier 2 — native Rust module `gabriel_fop_v1` (surgical):** refuses upload
bodies carrying the Java serialization magic marker; ordinary FO documents
pass unchanged.

## Authority lifecycle and negatives

Import 201, `activation: explicit_required`; publisher `enroll_key`, host
`inventory` + `approve`, reader `inspect` refused 403; tampered-statement admit
400; invalid-signature admit 403; `admit` prepared (not serving), `activate`
→ receipt `serving_now`, applied shards **2/2**. Revoke → the identical attack
gets **503** (fail-closed); re-approve + re-activate → 403 again. All recorded
in the evidence JSON.

## Honest scope

The fixture reproduces the serialized-marker delivery shape, not the full FOP
hyphenation API. Bypass variants (gadget encodings, alternate loaders,
compressed streams) are not bypass-tested; the rule is a lab-grade partial.
First live attempt hit the trailing-slash policy rejection (E04FF) and a
native-conditions exact-path mismatch; both fixed, case re-run clean. Module
binary SHA-256 `3db8222e…`, source `modules/gabriel_fop_v1.rs`.
