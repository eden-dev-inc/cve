# MLflow: artifact path traversal to remote code execution (CVE-2025-11201)

An unauthenticated caller can write files outside the MLflow Tracking Server's artifact root through a traversal path in the model-creation file API, and the written file executes with the service account's privileges. A tracking server exposed beyond its operators is therefore a remote-code-execution endpoint for anyone who can reach it.

## The vulnerability

MLflow's tracking server joins a user-supplied artifact path into a filesystem write without confining it to the artifact root, so traversal segments escape the store and the written file can execute later. Eden fronts the tracking server, so the traversal rides an HTTP request Eden can refuse before release; the marker rides the query string, which the interlay forwards verbatim.

## The Eden patch

**Tier 1 — declarative policy.** The recorded policy denies every method on `/api/2.0/mlflow-artifacts` and its descendants. This is a coarse rule: it also blocked the benign artifact download, which is the recorded false positive.

```json
{
  "version": 1,
  "profile": "http-structure-v1",
  "policy": {
    "version": 1,
    "rules": [
      {
        "scope": {
          "methods": [],
          "path": "/api/2.0/mlflow-artifacts",
          "descendants": true
        },
        "require": {
          "kind": "deny"
        }
      }
    ]
  }
}
```

**Tier 2 — native Rust module.** `gabriel_mlflow_v1` waits for a complete request, matches targets starting with `/api/2.0/mlflow-artifacts`, and refuses any target or body carrying a raw or percent-encoded traversal marker (`../`, `..%2f`, `%2e%2e`, `..\`). Clean paths continue, which passed the benign probe.

```rust
const ROUTE: &[u8] = b"/api/2.0/mlflow-artifacts";
static MARKS: [&[u8]; 4] = [b"../", b"..%2f", b"%2e%2e", b"..\\"];
```

## Implement the remediation

The commands are operator examples for the recorded scope. Compare fixture routes and software selectors with the intended deployment before use. See [deployment prerequisites](../deployment.md) and the [API example](../../cve/CVE-2025-11201/http-request-filter/api.md).

1. **Prepare the target.** Verify the loaded MLflow version against the advisory. Use a compatible Eden HTTP interlay and an authenticated operator with Configure permission. Use the recorded declaration and the linked source.
2. **Apply the declarative policy.** Set `INTERLAY` to the target interlay UUID in the authenticated Eden CLI. Save the interlay's complete current settings, place the policy from this report in `settings.remediation`, and PATCH the full settings object with a fresh `Idempotency-Key`. Read the interlay back and confirm `remediation_status.state` is `ready`.
3. **Import and activate the native module.** Build the schema-2 archive from the linked source with the compatible SDK, verify its digest, and PUT it to the interlay's patch-packages endpoint. Import requires explicit activation: enroll the publisher key, attest the host inventory, inspect the returned configuration, obtain independent host approval, sign the typed statement, admit, and activate. Read the receipt until `serving_now` is true and the expected shards are acknowledged. Full command sequences are in the [API example](../../cve/CVE-2025-11201/http-request-filter/api.md).
4. **Verify, revoke, and restore.** Replay the benign and advisory-shaped probes and compare the backend counter. Revoke the operation and confirm the advisory-shaped request no longer succeeds; re-approve, re-admit, and reactivate a replacement operation to restore protection. Keep the route isolated during the change window.

**Vendor update.** Apply the fix for the installed release line. The [advisory](https://github.com/advisories/GHSA-5cvj-7rg6-jggj) documents affected versions and update guidance.

## Fixture and probes

The benign probe fetched a model file by its clean relative path. The advisory-shaped probe posted `path=..%2f..%2f..%2fpwn.py` with a Python body — the directory traversal the advisory names. The fixture incremented its marker when a file landed outside the artifact root.

## Measured comparison (2026-11-13 UTC)

The values after each status are the observed increases in the fixture's escaped-write counter. The declarative tier blocked the benign fetch (the recorded false positive); the module refused only the traversal-bearing request.

| Probe | Baseline | Declarative policy | Native module |
| --- | --- | --- | --- |
| Benign artifact fetch | 200, 0 | 403, 0 | 200, 0 |
| Advisory-shaped traversal write | 200, 1 | 403, 0 | 403, 0 |

The marker scan is over raw bytes, so double-encoding that decodes only inside MLflow (for example `..%252f`) was not refused and is a bypass to record. The gateway's own path validation rejected the same traversal shapes when placed in the request path (400), but query-borne traversal reached the backend unremediated in the baseline.



## Signed module authority

Import returned HTTP 201 with explicit activation required and signature verification deferred. Read-only inspection was refused (403) for the reader principal, admission of a tampered statement was rejected (400), and admission of an invalid signature was refused (403). The activation receipt reported the module serving on all 32 expected shards. After revocation the advisory-shaped probe received HTTP 503 (fail-closed); re-approval and reactivation restored the refusal.
