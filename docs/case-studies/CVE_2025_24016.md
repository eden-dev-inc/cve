# Wazuh: RCE via unsafe deserialization in the server API (CVE-2025-24016)

Wazuh servers expose an unsafe deserialization flaw letting an attacker run arbitrary Python code on the server — for example, shutting down the master — reachable over the network with only low-level API access. The security-monitoring platform becomes the compromise.

## The vulnerability

The Wazuh API deserializes caller-supplied data without type confinement, so a crafted payload executes as Python on the master. Eden fronts the Wazuh server, so the crafted request rides an HTTP request Eden can refuse before release.

## The Eden patch

**Tier 1 — declarative policy.** The recorded policy denies every method on the recorded fixture route and its descendants. This is a coarse rule: it also blocked the benign probe on the same route, which is the recorded false positive.

```json
{
  "version": 1,
  "profile": "http-structure-v1",
  "policy": {
    "version": 1,
    "rules": [
      {
        "scope": {
          "methods": [],
          "path": "/api",
          "descendants": true
        },
        "require": {
          "kind": "deny"
        }
      }
    ]
  }
}
```

**Tier 2 — native Rust module.** gabriel_wazuh_v1 waits for a complete request, matches Wazuh API routes, and refuses POST bodies carrying deserialization gadget markers (rO0AB, getRuntime, exec(, __import__, os.system, subprocess) — the serialized shapes that reach the evaluator. Clean API calls continue.

```rust
const ROUTE: &[u8] = b"/api";
static GADGETS: [&[u8]; 6] = [b"rO0AB", b"getRuntime", b"exec(", b"__import__", b"os.system", b"subprocess"];
```

## Implement the remediation

The commands are operator examples for the recorded scope. Compare fixture routes and software selectors with the intended deployment before use. See [deployment prerequisites](../deployment.md) and the [API example](../../cve/CVE-2025-24016/http-request-filter/api.md).

1. **Prepare the target.** Verify the loaded Wazuh version against the advisory. Use a compatible Eden HTTP interlay and an authenticated operator with Configure permission. Use the recorded declaration and the linked source.
2. **Apply the declaratory policy.** Set `INTERLAY` to the target interlay UUID in the authenticated Eden CLI. Save the interlay's complete current settings, place the policy from this report in `settings.remediation`, and PATCH the full settings object with a fresh `Idempotency-Key`. Read the interlay back and confirm `remediation_status.state` is `ready`.
3. **Import and activate the native module.** Build the schema-2 archive from the linked source with the compatible SDK, verify its digest, and PUT it to the interlay's patch-packages endpoint. Import requires explicit activation: enroll the publisher key, attest the host inventory, inspect the returned configuration, obtain independent host approval, sign the typed statement, admit, and activate. Read the receipt until `serving_now` is true and the expected shards are acknowledged. Full command sequences are in the [API example](../../cve/CVE-2025-24016/http-request-filter/api.md).
4. **Verify, revoke, and restore.** Replay the benign and advisory-shaped probes and compare the backend counter. Revoke the operation and confirm the advisory-shaped request no longer succeeds (fail-closed 503); re-approve, re-admit, and reactivate a replacement operation to restore protection.

**Vendor update.** The fixed release carries the durable repair; the [advisory](https://cve.now/CVE-2025-24016) links the vendor's update instructions where available. Eden's tiers are an enforcement stopgap for a deployment that cannot upgrade immediately.

## Fixture and probes

The benign probe listed agents with a clean request. The advisory-shaped probe posted a body carrying serialized-gadget markers. The fixture incremented its marker when a gadget-bearing body reached the deserialization path.

## Measured comparison (2026-11-14 UTC)

The values after each status are the observed increases in the fixture's effect counter.

| Probe | Baseline | Declarative policy | Native module |
| --- | --- | --- | --- |
| Benign clean agent list | 200, 0 | 403, 0 | 200, 0 |
| Advisory-shaped deser gadget | 200, 1 | 403, 0 | 403, 0 |

The rule matches the recorded gadget markers on API routes; gadget encodings avoiding these bytes (custom pickle streams) were not exercised and are a bypass to record. The real-world path is a low-level API account. The durable fix is the vendor's input-validation patch.

## Signed module authority
