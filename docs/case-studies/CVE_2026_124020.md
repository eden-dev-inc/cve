# CWP: host header injection poisons password-reset links (CVE-2026-124020)

Control Web Panel's host header handling lets an unauthenticated network attacker poison the password-reset link, capturing a victim's recovery token and setting a new password. The recovery flow is only as trustworthy as the host the panel believes it is serving.

## The vulnerability

The panel builds reset links from the caller-controlled Host header, so an attacker-directed link delivers the victim's recovery token to the attacker. Eden fronts the panel, so the poisoned-host reset request rides an HTTP request Eden can refuse before release.

## The Eden patch

**Tier 1 — declarative policy.** The recorded policy denies every method on the recorded fixture route and its descendants. This is a coarse rule: it also blocked the benign probe on the same route, which is the recorded false positive.

```json
{
  "version": 1,
  "profile": "http-structure-v1",
  "policy": {
    "version": 1,
    "rules": [
      {
        "scope": {
          "methods": [],
          "path": "/index.php",
          "descendants": true
        },
        "require": {
          "kind": "deny"
        }
      }
    ]
  }
}
```

**Tier 2 — native Rust module.** gabriel_cwphost_v1 waits for a complete request, matches the reset route, and refuses reset requests whose Host header is not the deployment's pinned panel host — the host-poisoning shape. Host headers matching the deployment continue. Host is an end-to-end header, so the module sees the client-supplied value before the panel does.

```rust
static PINNED: &[u8] = b"panel.corp.example";
```

## Implement the remediation

The commands are operator examples for the recorded scope. Compare fixture routes and software selectors with the intended deployment before use. See [deployment prerequisites](../deployment.md) and the [API example](../../cve/CVE-2026-124020/http-request-filter/api.md).

1. **Prepare the target.** Verify the loaded Control Web Panel version against the advisory. Use a compatible Eden HTTP interlay and an authenticated operator with Configure permission. Use the recorded declaration and the linked source.
2. **Apply the declaratory policy.** Set `INTERLAY` to the target interlay UUID in the authenticated Eden CLI. Save the interlay's complete current settings, place the policy from this report in `settings.remediation`, and PATCH the full settings object with a fresh `Idempotency-Key`. Read the interlay back and confirm `remediation_status.state` is `ready`.
3. **Import and activate the native module.** Build the schema-2 archive from the linked source with the compatible SDK, verify its digest, and PUT it to the interlay's patch-packages endpoint. Import requires explicit activation: enroll the publisher key, attest the host inventory, inspect the returned configuration, obtain independent host approval, sign the typed statement, admit, and activate. Read the receipt until `serving_now` is true and the expected shards are acknowledged. Full command sequences are in the [API example](../../cve/CVE-2026-124020/http-request-filter/api.md).
4. **Verify, revoke, and restore.** Replay the benign and advisory-shaped probes and compare the backend counter. Revoke the operation and confirm the advisory-shaped request no longer succeeds (fail-closed 503); re-approve, re-admit, and reactivate a replacement operation to restore protection.

**Vendor update.** The fixed release carries the durable repair; the [advisory](https://cve.now/CVE-2026-124020) links the vendor's update instructions where available. Eden's tiers are an enforcement stopgap for a deployment that cannot upgrade immediately.

## Fixture and probes

The benign probe requested a password reset with the deployment's real Host. The advisory-shaped probe sent the same reset with an attacker Host. The fixture incremented its marker when a reset link was built from a foreign host.

Read-only inspection was refused (403) for the reader principal, admission of a tampered statement was rejected (400), and admission of an invalid signature was refused (403).
