# Report-Info path traversal file read (CVE-2024-5273)

[Source and API bundle](../../cve/CVE-2024-5273/README.md)

*[cve.now](https://cve.now/CVE-2024-5273) entry. Product: report-info handler
(lab: `gabriel-jenkins-app`).*

Eden terminates the HTTP connection to the affected product, evaluates a
declarative policy and — in tier 2 — a separately compiled native Rust module
under signed module authority, before any byte reaches the application. It does
**not** patch the affected component; the vendor's fixed release remains the
durable repair.

**Status: Remediated (tier 1 + tier 2), live-proven 2026-11-11T16:49:02Z on the
installed `eden-product-release:1.103.0` lab container.**

## The vulnerability

The report-info handler reads a caller-supplied path without confinement,
returning file contents via `../` traversal. The fixture (`make_tplink23`)
reproduces the shape: a body carrying `../` records a file-read mark and
returns the planted `GABRIEL-SECRET-9f31` contents.

## The Eden patch

**Tier 1 — declarative policy (blunt, fail-closed):** deny every request under
`/report-info`, ordinary report requests included — false positives measured
below.

**Tier 2 — native Rust module `gabriel_tplink29_v1` (surgical):** refuses
bodies carrying parent-directory fragments (`../`, `..\`); ordinary report
requests pass unchanged.

## Authority lifecycle and negatives

`inventory` + `approve`, reader `inspect` refused 403; tampered-statement admit
