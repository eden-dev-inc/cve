# NetScaler: security-control bypass via HTTP request smuggling (CVE-2026-88773)

Inconsistent interpretation of HTTP request boundaries can let an unauthenticated attacker smuggle a request through affected NetScaler ADC and Gateway deployments. This can bypass controls and affect the integrity and confidentiality of traffic handled downstream.

**Patch title.** NetScaler HTTP Framing Guard (`netscaler-http-framing-guard` in the registry). The [original source snapshot](https://github.com/eden-dev-inc/cve/blob/9a7217a0a882374c5ab97d74c96df9b77637f923/docs/case-studies/modules/CVE-2026-88773.rs) preserves the source available for the historical report.

**Result.** Eden returned HTTP 400 for the malformed request in all three fixture configurations. The backend counter stayed at zero. The native module passed the benign probe.

## The vulnerability

The affected versions and upgrade guidance are listed above. The Eden policy and module were tested against the HTTP fixture described below.

## The Eden patch

**Tier 1 — declarative policy.** The recorded policy denies every method on the recorded fixture route and its descendants. This is a coarse rule: it also blocked the benign probe on the same route, which is the recorded false positive.

```json
{
  "version": 1,
  "profile": "http-structure-v1",
  "policy": {
    "version": 1,
    "rules": [
      {
        "scope": {
          "methods": [],
          "path": "/epa",
          "descendants": true
        },
        "require": {
          "kind": "deny"
        }
      }
    ]
  }
}
```

**Tier 2 — native Rust module.** The module source includes a rule to refuse a complete request containing both Content-Length and Transfer-Encoding. The interlay rejected the malformed probe before that rule could run in the tested configuration.

```rust
let has_cl = header_value(hdrs, b"content-length").is_some();
let has_te = header_value(hdrs, b"transfer-encoding").is_some();
```

## Implement the remediation

The commands are operator examples for the recorded scope. Compare fixture routes and software selectors with the intended deployment before use. See [deployment prerequisites](../deployment.md) and the [API example](../../cve/CVE-2026-88773/http-request-filter/api.md).

1. **Prepare the target.** Verify the loaded Citrix NetScaler ADC / NetScaler Gateway version against the advisory. Use a compatible Eden HTTP interlay and an authenticated operator with Configure permission. Use the recorded declaration and the linked source.
2. **Apply the declaratory policy.** Set `INTERLAY` to the target interlay UUID in the authenticated Eden CLI. Save the interlay's complete current settings, place the policy from this report in `settings.remediation`, and PATCH the full settings object with a fresh `Idempotency-Key`. Read the interlay back and confirm `remediation_status.state` is `ready`.
3. **Import and activate the native module.** Build the schema-2 archive from the linked source with the compatible SDK, verify its digest, and PUT it to the interlay's patch-packages endpoint. Import requires explicit activation: enroll the publisher key, attest the host inventory, inspect the returned configuration, obtain independent host approval, sign the typed statement, admit, and activate. Read the receipt until `serving_now` is true and the expected shards are acknowledged. Full command sequences are in the [API example](../../cve/CVE-2026-88773/http-request-filter/api.md).
4. **Verify the framing outcome.** Replay both probes in the authorized fixture. Check for HTTP 400 and an unchanged backend counter for the malformed probe in each configuration. Check the clean request separately and use the activation receipt to confirm the module is serving.

**Vendor update.** Follow the update instructions for the installed product and release line. [Vendor or publisher advisory](https://support.citrix.com/external/article/CTX697096)

## Fixture and probes

The benign probe sent a cleanly framed request. The marked fixture probe presented both framing headers with a chunked smuggled prefix — the classic CL.TE shape. The fixture's marker never fired because the interlay refused the frame before release at every tier.

## Measured comparison (2026-11-13 UTC)

The values after each status are the observed increases in the fixture's effect counter.

| Probe | Baseline | Declarative policy | Native module |

The baseline and declarative configurations returned a framing error. The native-module configuration reported E1A44 for malformed inspection input.

## Signed module activation

Import returned HTTP 201 with explicit activation required and signature verification deferred. Read-only inspection was refused (403) for the reader principal, admission of a tampered statement was rejected (400), and admission of an invalid signature was refused (403). The activation receipt reported the module serving on all 32 expected shards.

## Test scope

The synthetic request presented both Content-Length and Transfer-Encoding. The Eden interlay rejected it during framing or inspection in every arm, before the native rule could return a decision. The test did not exercise a NetScaler appliance or other smuggling variants.
