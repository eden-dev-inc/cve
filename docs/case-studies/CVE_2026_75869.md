# ManageEngine DDI Central: PowerShell injection via crafted DNS suffix values (CVE-2026-75869)

ManageEngine DDI Central combines an authorization bypass with PowerShell command injection: a logged-in non-administrative user can reach unauthorized Windows DHCP subnets and run arbitrary commands on the managed Windows DHCP servers through crafted DNS suffix values. The compromise of a DHCP management plane cascades to every network segment those servers address.

## The vulnerability

The console passes DNS suffix values into PowerShell commands on managed Windows servers without neutralizing them, so a low-privilege user injects commands. Eden fronts the DDI Central console, so the crafted suffix rides an HTTP request Eden can refuse before release.

## The Eden patch

**Tier 1 — declarative policy.** The recorded policy denies every method on the recorded fixture route and its descendants. This is a coarse rule: it also blocked the benign probe on the same route, which is the recorded false positive.

```json
{
  "version": 1,
  "profile": "http-structure-v1",
  "policy": {
    "version": 1,
    "rules": [
      {
        "scope": {
          "methods": [],
          "path": "/api/dhcp",
          "descendants": true
        },
        "require": {
          "kind": "deny"
        }
      }
    ]
  }
}
```

**Tier 2 — native Rust module.** gabriel_ddips_v1 waits for a complete request, matches DDI Central DHCP API routes, and refuses requests whose DNS suffix fields carry PowerShell-injection markers (;, $(, backtick, powershell) — the crafted-suffix shape that reaches the managed servers. Clean suffix values continue.

```rust
const ROUTE: &[u8] = b"/api/dhcp";
static MARKS: [&[u8]; 4] = [b";", b"$(", b"`", b"powershell"];
```

## Implement the remediation

The commands are operator examples for the recorded scope. Compare fixture routes and software selectors with the intended deployment before use. See [deployment prerequisites](../deployment.md) and the [API example](../../cve/CVE-2026-75869/http-request-filter/api.md).

1. **Prepare the target.** Verify the loaded Zohocorp ManageEngine DDI Central version against the advisory. Use a compatible Eden HTTP interlay and an authenticated operator with Configure permission. Use the recorded declaration and the linked source.
2. **Apply the declaratory policy.** Set `INTERLAY` to the target interlay UUID in the authenticated Eden CLI. Save the interlay's complete current settings, place the policy from this report in `settings.remediation`, and PATCH the full settings object with a fresh `Idempotency-Key`. Read the interlay back and confirm `remediation_status.state` is `ready`.
3. **Import and activate the native module.** Build the schema-2 archive from the linked source with the compatible SDK, verify its digest, and PUT it to the interlay's patch-packages endpoint. Import requires explicit activation: enroll the publisher key, attest the host inventory, inspect the returned configuration, obtain independent host approval, sign the typed statement, admit, and activate. Read the receipt until `serving_now` is true and the expected shards are acknowledged. Full command sequences are in the [API example](../../cve/CVE-2026-75869/http-request-filter/api.md).
4. **Verify, revoke, and restore.** Replay the benign and advisory-shaped probes and compare the backend counter. Revoke the operation and confirm the advisory-shaped request no longer succeeds (fail-closed 503); re-approve, re-admit, and reactivate a replacement operation to restore protection.

**Vendor update.** The fixed release carries the durable repair; the [advisory](https://cve.now/CVE-2026-75869) links the vendor's update instructions where available. Eden's tiers are an enforcement stopgap for a deployment that cannot upgrade immediately.

## Fixture and probes

The benign probe created a DHCP subnet with the clean suffix corp.example. The advisory-shaped probe used a suffix carrying a PowerShell command. The fixture incremented its marker when an injection-bearing suffix reached the console handler.

## Measured comparison (2026-11-13 UTC)

The values after each status are the observed increases in the fixture's effect counter.

| Probe | Baseline | Declarative policy | Native module |
| --- | --- | --- | --- |
| Benign clean suffix | 200, 0 | 403, 0 | 200, 0 |
| Advisory-shaped PowerShell suffix | 200, 1 | 403, 0 | 403, 0 |

The rule matches the recorded PowerShell markers in DNS suffix fields on DHCP API routes; the authorization-bypass half of the flaw (reaching unauthorized subnets) has no generic request signature and is not addressed by this rule. PowerShell encodings without these markers are a bypass to record. The durable fix is the vendor's patch.
