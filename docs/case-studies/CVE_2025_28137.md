# TOTOLINK A810R: pre-authentication command injection (CVE-2025-28137)

An unauthenticated caller can execute operating-system commands on the affected TOTOLINK A810R firmware through the NoticeUrl input to setNoticeCfg. Exposure of the router's management interface can give a remote attacker control of the device.

**Result.** The injected command raised the backend counter in the baseline (200, +1). The declarative tier refused it (403, benign false positive recorded). The native module refused the injected login (403, counter unchanged) while the benign credential login stayed HTTP 200. Recorded through Eden 1.103.0 on 2026-11-13 (UTC).

## The vulnerability

The advisory identifies command injection through the NoticeUrl parameter of setNoticeCfg. The Eden fixture instead exercised shell markers in a synthetic login request.

## The Eden patch

**Tier 1 — declarative policy.** The recorded policy denies every method on /cgi-bin/login.cgi and its descendants. This blocks every login, benign or not (the recorded false positive) — an emergency posture.

```json
{
  "version": 1,
  "profile": "http-structure-v1",
  "policy": {
    "version": 1,
    "rules": [
      {
        "scope": {
          "methods": [],
          "path": "/cgi-bin/login.cgi",
          "descendants": true
        },
        "require": {
          "kind": "deny"
        }
      }
    ]
  }
}
```

**Tier 2 — native Rust module.** gabriel_totolink_v1 waits for a complete request, matches targets starting with /cgi-bin/login.cgi, and refuses bodies carrying shell metacharacter markers (;, $(, backtick) or a telnet token. Clean credential bodies continue.

```rust
const ROUTE: &[u8] = b"/cgi-bin/login.cgi";
static MARKS: [&[u8]; 4] = [b";", b"$(", b"`", b"telnet"];
```

## Implement the remediation

The commands are operator examples for the recorded scope. Compare fixture routes and software selectors with the intended deployment before use. See [deployment prerequisites](../deployment.md) and the [API example](../../cve/CVE-2025-28137/http-request-filter/api.md).

1. **Prepare the target.** Verify the loaded TOTOLINK A810R version against the advisory. Use a compatible Eden HTTP interlay and an authenticated operator with Configure permission. Use the recorded declaration and the linked source.
2. **Apply the declarative policy.** Set `INTERLAY` to the target interlay UUID in the authenticated Eden CLI. Save the interlay's complete current settings, place the policy from this report in `settings.remediation`, and PATCH the full settings object with a fresh `Idempotency-Key`. Read the interlay back and confirm `remediation_status.state` is `ready`.
3. **Import and activate the native module.** Build the schema-2 archive from the linked source with the compatible SDK, verify its digest, and PUT it to the interlay's patch-packages endpoint. Import requires explicit activation: enroll the publisher key, attest the host inventory, inspect the returned configuration, obtain independent host approval, sign the typed statement, admit, and activate. Read the receipt until `serving_now` is true and the expected shards are acknowledged. Full command sequences are in the [API example](../../cve/CVE-2025-28137/http-request-filter/api.md).
4. **Verify, revoke, and restore.** Replay the benign and advisory-shaped probes and compare the backend counter. Revoke the operation and confirm the marked fixture request no longer succeeds (fail-closed 503); re-approve, re-admit, and reactivate a replacement operation to restore protection.

**Vendor update.** Check the advisory and the vendor's release channel for a fix. Restrict the affected feature's exposure while a fix is unavailable. [Advisory reference](https://www.cve.org/CVERecord?id=CVE-2025-28137)

## Fixture and probes

The benign probe posted an ordinary credential login. The marked fixture probe appended a metacharacter command (a telnet launcher) to the password field. The fixture incremented its marker when injected commands reached its shell.
