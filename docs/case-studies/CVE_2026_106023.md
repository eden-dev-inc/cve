# Apache HTTP Server: mod_md NULL pointer dereference leads to child process crash (CVE-2026-106023)

[Source and API bundle](../../cve/CVE-2026-106023/README.md)

*[cve.now](https://cve.now/CVE-2026-106023) entry. Product: Apache HTTP Server
(lab: `gabriel-modmd-app`).*

Eden terminates the HTTP connection to the affected product, evaluates a
declarative policy and — in tier 2 — a separately compiled native Rust module
under signed module authority, before any byte reaches the application. It does
**not** patch the affected component; the vendor's fixed release remains the
durable repair.

**Status: Remediated (tier 1 + tier 2), live-proven 2026-11-11T17:09:04Z on the
installed `eden-product-release:1.103.0` lab container.**

## The vulnerability

`mod_md` dereferences a parsed session pointer without a NULL check, so a
crafted managed-domain session marker crashes the child process. The fixture
(`fixtures10.py`, `make_modmd`, port 18314) reproduces the delivery shape: a
request whose `MD-Session` header carries the NULL marker records a
child-crash mark.

## The Eden patch

**Tier 1 — declarative policy (blunt, fail-closed):** deny every request under
`/md` (non-slash scope — the interlay security policy rejects trailing-slash
deny scopes), legitimate managed-domain status checks included — false
positives measured below.

**Tier 2 — native Rust module `gabriel_modmd_v1` (surgical):** refuses requests
whose `MD-Session` header value equals the NULL marker; ordinary session
markers (`acct-1`) pass unchanged.

## Authority lifecycle and negatives

Import 201, `activation: explicit_required`; publisher `enroll_key`, host
`inventory` + `approve`, reader `inspect` refused 403; tampered-statement admit
400; invalid-signature admit 403; `admit` prepared (not serving), `activate`
→ receipt `serving_now`, applied shards **2/2**. Revoke → the identical attack
gets **503** (fail-closed); re-approve + re-activate → 403 again. All recorded
in the evidence JSON.

## Honest scope

The fixture reproduces the poisoned-session delivery shape, not the full
mod_md surface. Bypass variants (alternate headers, other NULL-typed fields)
are not bypass-tested; the rule is a lab-grade partial. First live attempt hit
the trailing-slash policy rejection (E04FF) and a native-conditions exact-path
mismatch; both were fixed and the case re-run clean — recorded honestly here.
Module binary SHA-256 `eca6e8cd…`, source `modules/gabriel_modmd_v1.rs`.
