# UniFi OS: path traversal reads underlying system files (CVE-2026-34909)

An attacker with network access to an affected UniFi OS device can read files on its underlying system through path traversal. Ubiquiti says those files could be used to access an underlying account.

## Synthetic HTTP controls

**Tier 1 — declarative policy.** The recorded policy denies every method on the recorded fixture route and its descendants. This is a coarse rule: it also blocked the benign probe on the same route, which is the recorded false positive.

```json
{
  "version": 1,
  "profile": "http-structure-v1",
  "policy": {
    "version": 1,
    "rules": [
      {
        "scope": {
          "methods": [],
          "path": "/proxy/network/api",
          "descendants": true
        },
        "require": {
          "kind": "deny"
        }
      }
    ]
  }
}
```

**Tier 2 — native Rust module.** On the /proxy/network/api prefix, the shared rule scans the target and body for selected traversal and shell strings.

```rust
const ROUTE: &[u8] = b"/proxy/network/api";
static MARKS: [&[u8]; 8] = [b"../", b"..%2f", b"%2e%2e", b"/etc/", b"file:", b";", b"$(", b"`"];
```

## Implement the remediation

**Vendor update.** Identify the device model and use Ubiquiti Bulletin 064 to select the matching fixed firmware. Confirm that the installed release is on the supported track for that device. [Vendor instructions](https://community.ui.com/releases/Security-Advisory-Bulletin-064-064/84811c09-4cf4-42ab-bd61-cc994445963b).

The published package uses the build name above. Verify its own archive digest before import. Use the [fixture API example](../../cve/CVE-2026-34909/http-request-filter/api.md) to reproduce the recorded comparison. It covers the declaration, signed module activation, verification, revocation, and restoration.

## Fixture and probes

The benign probe read a controller file by its clean path. The marked probe requested a traversal path to a system file. The fixture incremented its marker when a traversal-bearing path reached the file handler.

## Test scope

On the /proxy/network/api prefix, the shared rule scans the target and body for selected traversal and shell strings. The fixture did not resolve a filesystem path, read host files, or take over a UniFi account.

## Signed module authority

Import returned HTTP 201 with explicit activation required and signature verification deferred. Read-only inspection was refused (403) for the reader principal, admission of a tampered statement was rejected (400), and admission of an invalid signature was refused (403). The activation receipt reported the module serving on all 32 expected shards. After revocation the marked probe received HTTP 503 (fail-closed); re-approval and reactivation restored the refusal (403, counter unchanged).
