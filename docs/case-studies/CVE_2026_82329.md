# Artifactory: authentication bypass to administrative access (CVE-2026-82329)

JFrog Artifactory has an authentication weakness letting a remote attacker gain administrative access without valid credentials — the artifact repository compromise cascades to every artifact, pipeline, and deployment it feeds.

## The vulnerability

Artifactory's API path authentication can be bypassed under certain conditions, so an unauthenticated caller reaches administrative operations. Eden fronts the Artifactory instance, so the unauthenticated API request rides an HTTP request Eden can refuse before release.

## The Eden patch

**Tier 1 — declarative policy.** The recorded policy denies every method on the recorded fixture route and its descendants. This is a coarse rule: it also blocked the benign probe on the same route, which is the recorded false positive.

```json
{
  "version": 1,
  "profile": "http-structure-v1",
  "policy": {
    "version": 1,
    "rules": [
      {
        "scope": {
          "methods": [],
          "path": "/artifactory/api",
          "descendants": true
        },
        "require": {
          "kind": "deny"
        }
      }
    ]
  }
}
```

**Tier 2 — native Rust module.** gabriel_artifactory_v1 waits for a complete request, matches Artifactory API routes, and refuses unauthenticated requests on them — the unbound bypass-call shape the flaw exposes. Authenticated API calls continue.

```rust
const ROUTE: &[u8] = b"/artifactory/api";
```

## Implement the remediation

The commands are operator examples for the recorded scope. Compare fixture routes and software selectors with the intended deployment before use. See [deployment prerequisites](../deployment.md) and the [API example](../../cve/CVE-2026-82329/http-request-filter/api.md).

1. **Prepare the target.** Verify the loaded JFrog Artifactory version against the advisory. Use a compatible Eden HTTP interlay and an authenticated operator with Configure permission. Use the recorded declaration and the linked source.
2. **Apply the declaratory policy.** Set `INTERLAY` to the target interlay UUID in the authenticated Eden CLI. Save the interlay's complete current settings, place the policy from this report in `settings.remediation`, and PATCH the full settings object with a fresh `Idempotency-Key`. Read the interlay back and confirm `remediation_status.state` is `ready`.
3. **Import and activate the native module.** Build the schema-2 archive from the linked source with the compatible SDK, verify its digest, and PUT it to the interlay's patch-packages endpoint. Import requires explicit activation: enroll the publisher key, attest the host inventory, inspect the returned configuration, obtain independent host approval, sign the typed statement, admit, and activate. Read the receipt until `serving_now` is true and the expected shards are acknowledged. Full command sequences are in the [API example](../../cve/CVE-2026-82329/http-request-filter/api.md).
4. **Verify, revoke, and restore.** Replay the benign and advisory-shaped probes and compare the backend counter. Revoke the operation and confirm the advisory-shaped request no longer succeeds (fail-closed 503); re-approve, re-admit, and reactivate a replacement operation to restore protection.

**Vendor update.** The fixed release carries the durable repair; the [advisory](https://cve.now/CVE-2026-82329) links the vendor's update instructions where available. Eden's tiers are an enforcement stopgap for a deployment that cannot upgrade immediately.

## Fixture and probes

The benign probe performed an API write with a valid Art API token. The advisory-shaped probe performed the same write with no credentials. The fixture incremented its marker when an unauthenticated request reached the API handler.

## Measured comparison (2026-11-14 UTC)

The values after each status are the observed increases in the fixture's effect counter.

| Probe | Baseline | Declarative policy | Native module |
| --- | --- | --- | --- |
| Benign authed API write | 200, 0 | 403, 0 | 200, 0 |
| Advisory-shaped unauth admin access | 200, 1 | 403, 0 | 403, 0 |

The module enforces an authentication-presence contract on API routes; it does not validate the credential, so a forged-but-present token passes and is a bypass to record. The vendor's exact bypass conditions are not published, so the fixture delivers the binding shape honestly. The durable fix is the vendor's patched release.

## Signed module authority

Read-only inspection was refused (403) for the reader principal, admission of a tampered statement was rejected (400), and admission of an invalid signature was refused (403).
