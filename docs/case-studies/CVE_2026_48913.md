# Apache mod_http2: memory corruption when file handles exhausted (CVE-2026-48913)

*[cve.now](https://cve.now/CVE-2026-48913) entry. The experiment used a synthetic HTTP fixture.*

Eden terminates the HTTP connection to the affected product, evaluates a
declarative policy and — in tier 2 — a separately compiled native Rust module
under signed module authority, before any byte reaches the application. It does
**not** patch the affected component; the vendor's fixed release remains the
durable repair.

**Status: Declarative route-deny fixture comparison recorded.** The fixture ran against Eden 1.103.0.

## The vulnerability

mod_http2 corrupts memory when file handles are exhausted by crafted request streams (high, 7.3). File-descriptor exhaustion is process state — not observable at the request stage; tier-2 is NA-grade and the tier-1 window deny is proven live.

## The Eden patch

**Tier 1 — declarative policy (blunt, fail-closed):** deny every request under
`/h2frame` (non-slash scope), legitimate traffic included — false positives
measured below.

**Tier 2:** the case records a declarative result. The test scope below explains the native module limitation.

## Measured comparison (2026-11-12 UTC)

The comparison covers the baseline and the declarative route deny:

- **Baseline (no remediation):** benign 200, attack 200 with the primitive
  recorded at the fixture oracle
- **Tier 1 (deny):** both probes refused 403 (blunt, false positives included)
- **Tier 2 (module):** pass-through — no module (NA-grade)

## Authority lifecycle and negatives

Tier-1 window deny applied and revoked live; no tier-2 module exists for this stateful primitive.

## Test scope

The fixture reproduces the delivery shape with a harmless marker effect, not
the full product surface. Bypass variants (encodings, alternate routes, sibling
entry points) are **not bypass-tested**; the rule is a lab-grade partial by
construction. See the tier-2 note above for this case's stateful or transport-level limitation.
