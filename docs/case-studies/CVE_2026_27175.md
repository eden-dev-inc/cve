# MajorDoMo: shell command injection in the rc endpoint (CVE-2026-27175)

MajorDoMo can be attacked remotely, without logging in or any user action, to run commands on the server through shell command injection in the rc endpoint. The advisory describes a race with an unauthenticated worker script, and public exploit code — including a Metasploit module — exists.

## The vulnerability

The rc endpoint passes crafted parameter values into shell commands, so an unauthenticated caller executes with the server's privileges once the worker race is satisfied. Eden fronts the MajorDoMo web tier, so the injection-bearing request rides an HTTP request Eden can refuse before release.

## The Eden patch

**Tier 1 — declarative policy.** The recorded policy denies every method on the recorded fixture route and its descendants. This is a coarse rule: it also blocked the benign probe on the same route, which is the recorded false positive.

```json
{
  "version": 1,
  "profile": "http-structure-v1",
  "policy": {
    "version": 1,
    "rules": [
      {
        "scope": {
          "methods": [],
          "path": "/rc",
          "descendants": true
        },
        "require": {
          "kind": "deny"
        }
      }
    ]
  }
}
```

**Tier 2 — native Rust module.** gabriel_majordomo_v1 waits for a complete request, matches rc routes, and refuses targets or bodies carrying shell metacharacter markers — raw or percent-encoded forms (;, $(, backtick, %3b, %24(, %60). Clean rc requests continue.

```rust
const ROUTE: &[u8] = b"/rc";
static MARKS: [&[u8]; 6] = [b";", b"$(", b"`", b"%3b", b"%24(", b"%60"];
```

## Implement the remediation

The commands are operator examples for the recorded scope. Compare fixture routes and software selectors with the intended deployment before use. See [deployment prerequisites](../deployment.md) and the [API example](../../cve/CVE-2026-27175/http-request-filter/api.md).

1. **Prepare the target.** Verify the loaded MajorDoMo version against the advisory. Use a compatible Eden HTTP interlay and an authenticated operator with Configure permission. Use the recorded declaration and the linked source.
2. **Apply the declaratory policy.** Set `INTERLAY` to the target interlay UUID in the authenticated Eden CLI. Save the interlay's complete current settings, place the policy from this report in `settings.remediation`, and PATCH the full settings object with a fresh `Idempotency-Key`. Read the interlay back and confirm `remediation_status.state` is `ready`.
3. **Import and activate the native module.** Build the schema-2 archive from the linked source with the compatible SDK, verify its digest, and PUT it to the interlay's patch-packages endpoint. Import requires explicit activation: enroll the publisher key, attest the host inventory, inspect the returned configuration, obtain independent host approval, sign the typed statement, admit, and activate. Read the receipt until `serving_now` is true and the expected shards are acknowledged. Full command sequences are in the [API example](../../cve/CVE-2026-27175/http-request-filter/api.md).
4. **Verify, revoke, and restore.** Replay the benign and advisory-shaped probes and compare the backend counter. Revoke the operation and confirm the advisory-shaped request no longer succeeds (fail-closed 503); re-approve, re-admit, and reactivate a replacement operation to restore protection.

**Vendor update.** The fixed release carries the durable repair; the [advisory](https://cve.now/CVE-2026-27175) links the vendor's update instructions where available. Eden's tiers are an enforcement stopgap for a deployment that cannot upgrade immediately.

## Fixture and probes

The benign probe issued a clean rc check request. The advisory-shaped probe carried a metacharacter command in the op parameter. The fixture incremented its marker when an injection-bearing request reached the rc handler.

## Measured comparison (2026-11-13 UTC)

The values after each status are the observed increases in the fixture's effect counter.

| Probe | Baseline | Declarative policy | Native module |
| --- | --- | --- | --- |
| Benign rc check | 200, 0 | 403, 0 | 200, 0 |
| Advisory-shaped injected command | 200, 1 | 403, 0 | 403, 0 |

The rule refuses injection markers on rc routes regardless of the worker race — it blocks the crafted request primitive, not the race itself, and clean-looking requests that still win the race are outside this rule's signature. The durable fix is the vendor's patch.

## Signed module authority

Import returned HTTP 201 with explicit activation required and signature verification deferred. Read-only inspection was refused (403) for the reader principal, admission of a tampered statement was rejected (400), and admission of an invalid signature was refused (403). After revocation the advisory-shaped probe received HTTP 503 (fail-closed); re-approval and reactivation restored the refusal (403, counter unchanged).
