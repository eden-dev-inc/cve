# FortiOS family: file write/delete via traversal in CLI arguments (CVE-2025-61624)

A path traversal flaw across FortiOS, FortiProxy, FortiSwitchManager and FortiPAM lets a logged-in attacker with a high-privilege admin account write or delete arbitrary files on the device by supplying crafted CLI arguments. Admin-plane compromise on these devices is full device control.

## The vulnerability

The management API forwards crafted arguments into file operations without confining paths, so traversal sequences write or delete arbitrary files. Eden fronts the device's management interface, so the crafted request rides an HTTP request Eden can refuse before release.

## The Eden patch

**Tier 1 — declarative policy.** The recorded policy denies every method on the recorded fixture route and its descendants. This is a coarse rule: it also blocked the benign probe on the same route, which is the recorded false positive.

```json
{
  "version": 1,
  "profile": "http-structure-v1",
  "policy": {
    "version": 1,
    "rules": [
      {
        "scope": {
          "methods": [],
          "path": "/api/v2",
          "descendants": true
        },
        "require": {
          "kind": "deny"
        }
      }
    ]
  }
}
```

**Tier 2 — native Rust module.** gabriel_fortinet_v1 waits for a complete request, matches the v2 API route, and refuses targets or bodies carrying traversal markers (../, ..%2f, %2e%2e) — the crafted-argument shape the CLI arguments accept.

```rust
const ROUTE: &[u8] = b"/api/v2";
static MARKS: [&[u8]; 3] = [b"../", b"..%2f", b"%2e%2e"];
```

## Implement the remediation

The commands are operator examples for the recorded scope. Compare fixture routes and software selectors with the intended deployment before use. See [deployment prerequisites](../deployment.md) and the [API example](../../cve/CVE-2025-61624/http-request-filter/api.md).

1. **Prepare the target.** Verify the loaded FortiOS / FortiProxy / FortiSwitchManager / FortiPAM version against the advisory. Use a compatible Eden HTTP interlay and an authenticated operator with Configure permission. Use the recorded declaration and the linked source.
2. **Apply the declaratory policy.** Set `INTERLAY` to the target interlay UUID in the authenticated Eden CLI. Save the interlay's complete current settings, place the policy from this report in `settings.remediation`, and PATCH the full settings object with a fresh `Idempotency-Key`. Read the interlay back and confirm `remediation_status.state` is `ready`.
3. **Import and activate the native module.** Build the schema-2 archive from the linked source with the compatible SDK, verify its digest, and PUT it to the interlay's patch-packages endpoint. Import requires explicit activation: enroll the publisher key, attest the host inventory, inspect the returned configuration, obtain independent host approval, sign the typed statement, admit, and activate. Read the receipt until `serving_now` is true and the expected shards are acknowledged. Full command sequences are in the [API example](../../cve/CVE-2025-61624/http-request-filter/api.md).
4. **Verify, revoke, and restore.** Replay the benign and advisory-shaped probes and compare the backend counter. Revoke the operation and confirm the advisory-shaped request no longer succeeds (fail-closed 503); re-approve, re-admit, and reactivate a replacement operation to restore protection.

**Vendor update.** The fixed release carries the durable repair; the [advisory](https://cve.now/CVE-2025-61624) links the vendor's update instructions where available. Eden's tiers are an enforcement stopgap for a deployment that cannot upgrade immediately.

## Fixture and probes

The benign probe fetched a system status through the API. The advisory-shaped probe issued a config call carrying a traversal-marked argument. The fixture incremented its marker when a traversal argument reached its file handler.

## Measured comparison (2026-11-13 UTC)

The values after each status are the observed increases in the fixture's effect counter.

| Probe | Baseline | Declarative policy | Native module |
| --- | --- | --- | --- |
| Benign system status fetch | 200, 0 | 403, 0 | 200, 0 |
| Advisory-shaped traversal argument | 200, 1 | 403, 0 | 403, 0 |

The rule matches raw and percent-encoded traversal markers on the v2 API route; other management surfaces (SSH CLI) are outside HTTP and were not exercised. The real-world path is an authenticated high-privilege admin — the recorded risk is escalation to arbitrary file write/delete.

## Signed module authority

Import returned HTTP 201 with explicit activation required and signature verification deferred. Read-only inspection was refused (403) for the reader principal, admission of a tampered statement was rejected (400), and admission of an invalid signature was refused (403). The activation receipt reported the module serving on all 32 expected shards. After revocation the advisory-shaped probe received HTTP 503 (fail-closed); re-approval and reactivation restored the refusal (403, counter unchanged).
