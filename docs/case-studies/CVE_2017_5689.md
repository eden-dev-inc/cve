# Intel AMT: complete web authentication bypass via digest handling (CVE-2017-5689)

Intel Active Management Technology and Intel Standard Manageability let a network attacker completely bypass web interface authentication — logging in as admin with any password, or even an empty digest response. Unauthenticated admin access to the out-of-band management controller is full device control, below the OS.

## The vulnerability

AMT's digest handling accepts an empty response as valid, so an unauthenticated caller reaches the management interface as admin. Eden fronts the AMT web listener, so the credential-less request rides an HTTP request Eden can refuse before release.

## The Eden patch

**Tier 1 — declarative policy.** The recorded policy denies every method on the recorded fixture route and its descendants. This is a coarse rule: it also blocked the benign probe on the same route, which is the recorded false positive.

```json
{
  "version": 1,
  "profile": "http-structure-v1",
  "policy": {
    "version": 1,
    "rules": [
      {
        "scope": {
          "methods": [],
          "path": "/pages",
          "descendants": true
        },
        "require": {
          "kind": "deny"
        }
      }
    ]
  }
}
```

**Tier 2 — native Rust module.** gabriel_intelamt_v1 waits for a complete request, matches AMT web routes, and refuses requests whose Authorization header is missing or carries an empty digest — the exact shape the parser mishandles.

```rust
//! refuse AMT web requests with empty or missing credentials.
```

## Implement the remediation

The commands are operator examples for the recorded scope. Compare fixture routes and software selectors with the intended deployment before use. See [deployment prerequisites](../deployment.md) and the [API example](../../cve/CVE-2017-5689/http-request-filter/api.md).

1. **Prepare the target.** Verify the loaded Intel AMT / ISM version against the advisory. Use a compatible Eden HTTP interlay and an authenticated operator with Configure permission. Use the recorded declaration and the linked source.
2. **Apply the declaratory policy.** Set `INTERLAY` to the target interlay UUID in the authenticated Eden CLI. Save the interlay's complete current settings, place the policy from this report in `settings.remediation`, and PATCH the full settings object with a fresh `Idempotency-Key`. Read the interlay back and confirm `remediation_status.state` is `ready`.
3. **Import and activate the native module.** Build the schema-2 archive from the linked source with the compatible SDK, verify its digest, and PUT it to the interlay's patch-packages endpoint. Import requires explicit activation: enroll the publisher key, attest the host inventory, inspect the returned configuration, obtain independent host approval, sign the typed statement, admit, and activate. Read the receipt until `serving_now` is true and the expected shards are acknowledged. Full command sequences are in the [API example](../../cve/CVE-2017-5689/http-request-filter/api.md).
4. **Verify, revoke, and restore.** Replay the benign and advisory-shaped probes and compare the backend counter. Revoke the operation and confirm the advisory-shaped request no longer succeeds (fail-closed 503); re-approve, re-admit, and reactivate a replacement operation to restore protection.

**Vendor update.** The fixed release carries the durable repair; the [advisory](https://cve.now/CVE-2017-5689) links the vendor's update instructions where available. Eden's tiers are an enforcement stopgap for a deployment that cannot upgrade immediately.

## Fixture and probes

The benign probe posted with a valid digest authorization. The advisory-shaped probe posted the bare 'Digest' header with no response. The fixture incremented its marker when an empty credential reached its auth parser.

## Measured comparison (2026-11-13 UTC)

The values after each status are the observed increases in the fixture's effect counter.

| Probe | Baseline | Declarative policy | Native module |
| --- | --- | --- | --- |
| Benign digest-authorized request | 200, 0 | 403, 0 | 200, 0 |
| Advisory-shaped empty digest | 200, 1 | 403, 0 | 403, 0 |

The rule refuses empty or absent Authorization on AMT routes only; other AMT vectors (KVM, serial-over-LAN ports) are outside HTTP and were not exercised. AMT normally listens on its own interface — front it as its own interlay.

## Signed module authority

Import returned HTTP 201 with explicit activation required and signature verification deferred. Read-only inspection was refused (403) for the reader principal, admission of a tampered statement was rejected (400), and admission of an invalid signature was refused (403). The activation receipt reported the module serving on all 32 expected shards. After revocation the advisory-shaped probe received HTTP 503 (fail-closed); re-approval and reactivation restored the refusal (403, counter unchanged).
