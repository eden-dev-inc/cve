# Apache mod_userdir: information disclosure (CVE-2026-79768)

*[cve.now](https://cve.now/CVE-2026-79768) entry. The experiment used a synthetic HTTP fixture.*

Eden terminates the HTTP connection to the affected product, evaluates a
declarative policy and — in tier 2 — a separately compiled native Rust module
under signed module authority, before any byte reaches the application. It does
**not** patch the affected component; the vendor's fixed release remains the
durable repair.

**Status: Two-tier lab fixture comparison recorded.** The fixture ran against Eden 1.103.0.

[Module source](modules/gabriel_userdirtrav_v1.rs)

## The vulnerability

mod_userdir discloses user home directories via crafted tilde-user traversal requests (medium, 5.3). The fixture reproduces the delivery shape with the traversal URL-encoded in the query string (raw traversal targets are transport-refused, recorded as a product note).

## The Eden patch

**Tier 1 — declarative policy (blunt, fail-closed):** deny every request under
`/users` (non-slash scope), legitimate traffic included — false positives
measured below.

**Tier 2 — native Rust module `gabriel_userdirtrav_v1` (surgical):**
refuses userdir targets carrying ~ plus encoded parent-directory fragments
query-form delivery; the raw path form is transport-refused by Eden

## Measured comparison (2026-11-12 UTC)

Summary of measured outcomes across the full authority
lifecycle (baseline → tier-1 → tier-2 → revoke → restore):

- **Baseline (no remediation):** benign 200, attack 200 with the primitive
  recorded at the fixture oracle
- **Tier 1 (deny):** both probes refused 403 (blunt, false positives included)
- **Tier 2 (module):** benign 200 / attack 403, zero backend effects

## Authority lifecycle and negatives

Import 201, `activation: explicit_required`; publisher `enroll_key`, host
`inventory` + `approve`, reader `inspect` refused 403; tampered-statement admit
400; invalid-signature admit 403; `admit` prepared (not serving), `activate`
→ receipt `serving_now`, all expected shards acknowledged the operation. Revoke → the identical attack
gets **503** (fail-closed); re-approve + re-activate → 403 again.

## Test scope

The fixture reproduces the delivery shape with a harmless marker effect, not
the full product surface. Bypass variants (encodings, alternate routes, sibling
entry points) are **not bypass-tested**; the rule is a lab-grade partial by
construction.
