# WWBN AVideo path traversal file read (CVE-2026-126804)

*[cve.now](https://cve.now/CVE-2026-126804) entry. The experiment used a synthetic HTTP fixture.*

Eden terminates the HTTP connection to the affected product, evaluates a
declarative policy and — in tier 2 — a separately compiled native Rust module
under signed module authority, before any byte reaches the application. It does
**not** patch the affected component; the vendor's fixed release remains the
durable repair.

**Status: Two-tier lab fixture comparison recorded.** The fixture ran against Eden 1.103.0.

[Module source](modules/gabriel_avideotrav_v1.rs)

## The vulnerability

WWBN AVideo 12.4–29.7.1 reads caller-supplied gallery paths without confinement, exposing arbitrary files via `../` traversal (high). The fixture reproduces the shape: a gallery query carrying `../` records a file-read mark.

## The Eden patch

**Tier 1 — declarative policy (blunt, fail-closed):** deny every request under
`/gallery` (non-slash scope), legitimate traffic included — false positives
measured below.

**Tier 2 — native Rust module `gabriel_avideotrav_v1` (surgical):** refuses gallery targets carrying parent-directory fragments; ordinary gallery queries pass unchanged.

## Measured comparison (2026-11-12 UTC)

| Probe | Request | Baseline | Tier 1 | Tier 2 (module) |
| --- | --- | --- | --- | --- |
| benign_gallery | GET `/gallery/list` | 200 | 403 | 200 |
| attack_gallery_trav | GET `/gallery?file=../../../etc/passwd` | 200 | 403 | 403 |

**Eden-added latency for the tier-2 remediation:** benign requests complete in **385 µs** mean (p50 369 µs, p95 477 µs) in-product, module evaluation included.
*Honest scope: lab fixtures on one host, fresh connection per measured
request, warm requests only; the module was reactivated with a fresh signed
statement per measurement; spans carry the full authority lineage (module
SHA-256, operation, publication).*


## Authority lifecycle and negatives

Import 201, `activation: explicit_required`; publisher `enroll_key`, host
`inventory` + `approve`, reader `inspect` refused 403; tampered-statement admit
400; invalid-signature admit 403; `admit` prepared (not serving), `activate`
→ receipt `serving_now`, all expected shards acknowledged the operation. Revoke → the identical attack
gets **503** (fail-closed); re-approve + re-activate → 403 again.

## Test scope

The fixture reproduces the delivery shape with a harmless marker effect, not
the full product surface. Bypass variants (encodings, alternate routes, sibling
entry points) are **not bypass-tested**; the rule is a lab-grade partial by
construction.
