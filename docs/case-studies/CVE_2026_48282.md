# ColdFusion: path traversal to code execution (CVE-2026-48282)

Adobe ColdFusion exposes a path traversal flaw letting an attacker access files outside the restricted directories — potentially running arbitrary code with the current user's privileges, with no user action required.

## The vulnerability

ColdFusion resolves caller-supplied paths outside the intended root, so traversal sequences read — and in chained forms, execute — beyond the restricted directories. Eden fronts the ColdFusion application server, so the crafted path rides an HTTP request Eden can refuse before release.

## The Eden patch

**Tier 1 — declarative policy.** The recorded policy denies every method on the recorded fixture route and its descendants. This is a coarse rule: it also blocked the benign probe on the same route, which is the recorded false positive.

```json
{
  "version": 1,
  "profile": "http-structure-v1",
  "policy": {
    "version": 1,
    "rules": [
      {
        "scope": {
          "methods": [],
          "path": "/api",
          "descendants": true
        },
        "require": {
          "kind": "deny"
        }
      }
    ]
  }
}
```

**Tier 2 — native Rust module.** gabriel_coldfusion_v1 waits for a complete request, matches ColdFusion application routes, and refuses targets or bodies carrying traversal markers (../, percent-encoded forms, /etc/, file:) — the escape shapes that reach the file access. Clean application requests continue.

```rust
static MARKS: [&[u8]; 5] = [b"../", b"..%2f", b"%2e%2e", b"/etc/", b"file:"];
```

## Implement the remediation

The commands are operator examples for the recorded scope. Compare fixture routes and software selectors with the intended deployment before use. See [deployment prerequisites](../deployment.md) and the [API example](../../cve/CVE-2026-48282/http-request-filter/api.md).

1. **Prepare the target.** Verify the loaded Adobe ColdFusion version against the advisory. Use a compatible Eden HTTP interlay and an authenticated operator with Configure permission. Use the recorded declaration and the linked source.
2. **Apply the declaratory policy.** Set `INTERLAY` to the target interlay UUID in the authenticated Eden CLI. Save the interlay's complete current settings, place the policy from this report in `settings.remediation`, and PATCH the full settings object with a fresh `Idempotency-Key`. Read the interlay back and confirm `remediation_status.state` is `ready`.
3. **Import and activate the native module.** Build the schema-2 archive from the linked source with the compatible SDK, verify its digest, and PUT it to the interlay's patch-packages endpoint. Import requires explicit activation: enroll the publisher key, attest the host inventory, inspect the returned configuration, obtain independent host approval, sign the typed statement, admit, and activate. Read the receipt until `serving_now` is true and the expected shards are acknowledged. Full command sequences are in the [API example](../../cve/CVE-2026-48282/http-request-filter/api.md).
4. **Verify, revoke, and restore.** Replay the benign and advisory-shaped probes and compare the backend counter. Revoke the operation and confirm the advisory-shaped request no longer succeeds (fail-closed 503); re-approve, re-admit, and reactivate a replacement operation to restore protection.

**Vendor update.** The fixed release carries the durable repair; the [advisory](https://cve.now/CVE-2026-48282) links the vendor's update instructions where available. Eden's tiers are an enforcement stopgap for a deployment that cannot upgrade immediately.

## Fixture and probes

The benign probe requested a clean user-info endpoint. The advisory-shaped probe supplied a traversal path through the same endpoint's path parameter. The fixture incremented its marker when a traversal-bearing path reached the handler.

## Measured comparison (2026-11-14 UTC)

The values after each status are the observed increases in the fixture's effect counter.

| Probe | Baseline | Declarative policy | Native module |
| --- | --- | --- | --- |
| Benign clean app request | 200, 0 | 403, 0 | 200, 0 |
| Advisory-shaped traversal read | 200, 1 | 403, 0 | 403, 0 |

The rule matches raw and percent-encoded traversal markers on the recorded route family; alternate encodings were not exercised. The durable fix is the vendor's path-canonicalization patch. This module also covers the sibling advisory CVE-2026-27305 (same traversal family).

## Signed module authority
