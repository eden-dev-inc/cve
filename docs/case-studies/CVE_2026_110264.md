# GitLab: code execution through the regex compiler (CVE-2026-110264)

GitLab's regex compilation evaluates crafted patterns in a way that escapes to code execution, reachable through the API. Like the CI-lint flaw (CVE-2026-97229), this is a crafted-regex family, and unauthenticated reachable surfaces make an exposed instance compromisable.

## The vulnerability

The regex compiler evaluates attacker-supplied patterns outside a safe evaluation context, so crafted constructs execute code with the server's privileges. Eden fronts the GitLab web tier, so the crafted pattern rides an HTTP request Eden can refuse before release.

## The Eden patch

**Tier 1 — declarative policy.** The recorded policy denies every method on the recorded fixture route and its descendants. This is a coarse rule: it also blocked the benign probe on the same route, which is the recorded false positive.

```json
{
  "version": 1,
  "profile": "http-structure-v1",
  "policy": {
    "version": 1,
    "rules": [
      {
        "scope": {
          "methods": [],
          "path": "/api/v4/projects",
          "descendants": true
        },
        "require": {
          "kind": "deny"
        }
      }
    ]
  }
}
```

**Tier 2 — native Rust module.** gabriel_gitlabre2_v1 waits for a complete request, matches the API v4 route, and refuses bodies carrying the crafted regex constructs recorded from the exploit family.

```rust
const ROUTE: &[u8] = b"/api/v4";
static MARKS: [&[u8]; 3] = [b"(?{", b"(?<", b"(*posix"];
```

## Implement the remediation

The commands are operator examples for the recorded scope. Compare fixture routes and software selectors with the intended deployment before use. See [deployment prerequisites](../deployment.md) and the [API example](../../cve/CVE-2026-110264/http-request-filter/api.md).

1. **Prepare the target.** Verify the loaded GitLab CE/EE version against the advisory. Use a compatible Eden HTTP interlay and an authenticated operator with Configure permission. Use the recorded declaration and the linked source.
2. **Apply the declaratory policy.** Set `INTERLAY` to the target interlay UUID in the authenticated Eden CLI. Save the interlay's complete current settings, place the policy from this report in `settings.remediation`, and PATCH the full settings object with a fresh `Idempotency-Key`. Read the interlay back and confirm `remediation_status.state` is `ready`.
3. **Import and activate the native module.** Build the schema-2 archive from the linked source with the compatible SDK, verify its digest, and PUT it to the interlay's patch-packages endpoint. Import requires explicit activation: enroll the publisher key, attest the host inventory, inspect the returned configuration, obtain independent host approval, sign the typed statement, admit, and activate. Read the receipt until `serving_now` is true and the expected shards are acknowledged. Full command sequences are in the [API example](../../cve/CVE-2026-110264/http-request-filter/api.md).
4. **Verify, revoke, and restore.** Replay the benign and advisory-shaped probes and compare the backend counter. Revoke the operation and confirm the advisory-shaped request no longer succeeds (fail-closed 503); re-approve, re-admit, and reactivate a replacement operation to restore protection.

**Vendor update.** The fixed release carries the durable repair; the [advisory](https://cve.now/CVE-2026-110264) links the vendor's update instructions where available. Eden's tiers are an enforcement stopgap for a deployment that cannot upgrade immediately.

## Fixture and probes

The benign probe posted an ordinary project create. The advisory-shaped probe embedded a crafted regex construct in the same field. The fixture incremented its marker when a crafted regex reached the compiler.

The marker set covers the recorded injection constructs on API v4; alternate regex escapes and other GitLab surfaces were not exercised. The compiler and CI-lint flaws share a marker family; this rule is scoped to the API v4 route.
