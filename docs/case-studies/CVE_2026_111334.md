# NetScaler ADC: memory overflow DoS in Endpoint Analysis (CVE-2026-111334)

An unauthenticated remote caller can drive a memory overflow in the NetScaler ADC / Gateway Endpoint Analysis (EPA/EPAS) component, causing unpredictable behavior or a denial of service. No login and no user interaction are required.

## The vulnerability

Citrix reports a memory overflow in Endpoint Analysis on affected ADC and Gateway versions. The Eden fixture used an oversized query value on a synthetic EPA route to measure whether the request reached its handler.

## The Eden patch

**Tier 1 — declarative policy.** The recorded policy denies every method on the recorded fixture route and its descendants. This is a coarse rule: it also blocked the benign probe on the same route, which is the recorded false positive.

```json
{
  "version": 1,
  "profile": "http-structure-v1",
  "policy": {
    "version": 1,
    "rules": [
      {
        "scope": {
          "methods": [],
          "path": "/epa",
          "descendants": true
        },
        "require": {
          "kind": "deny"
        }
      }
    ]
  }
}
```

**Tier 2 — native Rust module.** gabriel_nsepa_v1 waits for a complete request, matches the EPA route, and refuses any EPA scan request whose query carries a parameter value longer than 128 bytes — the oversized-value memory-overflow shape.

```rust
const ROUTE: &[u8] = b"/epa";
// refuse EPA scan parameters with values longer than 128 bytes
```

## Implement the remediation

The commands are operator examples for the recorded scope. Compare fixture routes and software selectors with the intended deployment before use. See [deployment prerequisites](../deployment.md) and the [API example](../../cve/CVE-2026-111334/http-request-filter/api.md).

1. **Prepare the target.** Verify the loaded Citrix NetScaler ADC / Gateway EPA version against the advisory. Use a compatible Eden HTTP interlay and an authenticated operator with Configure permission. Use the recorded declaration and the linked source.
2. **Apply the declaratory policy.** Set `INTERLAY` to the target interlay UUID in the authenticated Eden CLI. Save the interlay's complete current settings, place the policy from this report in `settings.remediation`, and PATCH the full settings object with a fresh `Idempotency-Key`. Read the interlay back and confirm `remediation_status.state` is `ready`.
3. **Import and activate the native module.** Build the schema-2 archive from the linked source with the compatible SDK, verify its digest, and PUT it to the interlay's patch-packages endpoint. Import requires explicit activation: enroll the publisher key, attest the host inventory, inspect the returned configuration, obtain independent host approval, sign the typed statement, admit, and activate. Read the receipt until `serving_now` is true and the expected shards are acknowledged. Full command sequences are in the [API example](../../cve/CVE-2026-111334/http-request-filter/api.md).
4. **Verify, revoke, and restore.** Replay the benign and advisory-shaped probes and compare the backend counter. Revoke the operation and confirm the advisory-shaped request no longer succeeds (fail-closed 503); re-approve, re-admit, and reactivate a replacement operation to restore protection.

**Vendor update.** Apply the vendor update for the installed release or model. [Advisory reference](https://support.citrix.com/support-home/kbsearch/article?articleNumber=CTX697305)

## Fixture and probes

The benign probe posted a short EPA scan request. The marked fixture probe posted a scan parameter with a 180-byte value. The fixture incremented its marker when an oversized scan parameter reached the EPA handler.

## Measured comparison (2026-11-13 UTC)

The values after each status are the observed increases in the fixture's effect counter.

| Probe | Baseline | Declarative policy | Native module |
| --- | --- | --- | --- |
| Benign EPA scan | 200, 0 | 403, 0 | 200, 0 |
| Advisory-shaped oversized scan | 200, 1 | 403, 0 | 403, 0 |

The rule refuses oversized parameter values on the EPA route; other overflow shapes (oversized aggregate bodies, header-borne) were not exercised. The threshold is a lab recording, not a vendor boundary.

## Signed module authority

Import returned HTTP 201 with explicit activation required and signature verification deferred. Read-only inspection was refused (403) for the reader principal, admission of a tampered statement was rejected (400), and admission of an invalid signature was refused (403). The activation receipt reported the module serving on all 32 expected shards. After revocation the advisory-shaped probe received HTTP 503 (fail-closed); re-approval and reactivation restored the refusal (403, counter unchanged).
