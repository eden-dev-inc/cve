# Airflow: broker command injection through the task queue (CVE-2020-11981)

Apache Airflow 1.10.10 and below with CeleryExecutor: an attacker who can connect to the broker (Redis, RabbitMQ) directly can inject commands that the Celery worker runs — the 2020 ancestor of the CVE-2026-68982 callback family. The direct vector is the broker wire; the module protects the API's task-queueing surface.

## The vulnerability

The executor runs broker-delivered task commands without origin verification, so broker-reachable injection executes on workers. Eden fronts the API server, so the unauthenticated queueing request rides an HTTP request Eden can refuse before release; the broker wire is a recorded protocol gap (see CVE-2026-68982).

## The Eden patch

**Tier 1 — declaratory policy.** The recorded policy denies every method on the recorded route family and its descendants. This is a coarse rule: it also blocked the benign probe on the same route, which is the recorded false positive.

```json
{
  "version": 1,
  "profile": "http-structure-v1",
  "policy": {
    "version": 1,
    "rules": [
      {
        "scope": {
          "methods": [],
          "path": "/api/v2/dags",
          "descendants": true
        },
        "require": {
          "kind": "deny"
        }
      }
    ]
  }
}
```

**Tier 2 — native Rust module.** airflow_celery_queue_guard waits for a complete request, matches task-instance and XCom routes, refuses unauthenticated writes, refuses deserialization gadget markers in body values, and refuses bulk PATCH/DELETE bodies whose dag_id differs from the path dag — the task-instance family's four shapes. Bound, clean, matching writes continue.

```rust
static GADGETS: [&[u8]; 6] = [b"__import__", b"os.system", b"import_string", b"subprocess", b"rO0AB", b"eval("];
```

## Implement the remediation

The commands are operator examples for the recorded scope. Compare fixture routes and software selectors with the intended deployment before use. See [deployment prerequisites](../deployment.md) and the [API example](../../cve/CVE-2020-11981/http-request-filter/api.md).

1. **Prepare the target.** Verify the loaded Apache Airflow 1.10.x (CeleryExecutor) version against the advisory. Use a compatible Eden HTTP interlay and an authenticated operator with Configure permission.
2. **Apply the declaratory policy.** Set `INTERLAY` to the target interlay UUID in the authenticated Eden CLI. Save the interlay's complete current settings, place the policy from this report in `settings.remediation`, and PATCH the full settings object with a fresh `Idempotency-Key`. Read the interlay back and confirm `remediation_status.state` is `ready`.
3. **Import and activate the native module.** Build the schema-2 archive from the linked source with the compatible SDK, verify its digest, and PUT it to the interlay's patch-packages endpoint. Import requires explicit activation: enroll the publisher key, attest the host inventory, inspect the returned configuration, obtain independent host approval, sign the typed statement, admit, and activate. Read the receipt until `serving_now` is true and the expected shards are acknowledged.
4. **Verify, revoke, and restore.** Replay the benign and advisory-shaped probes and compare the backend counter. Revoke the operation and confirm the advisory-shaped request no longer succeeds (fail-closed 503); re-approve, re-admit, and reactivate a replacement operation to restore protection.

**Vendor update.** The fixed release carries the durable repair; the [advisory](https://cve.now/CVE-2020-11981) links the vendor's update instructions where available. Eden's tiers are an enforcement stopgap for a deployment that cannot upgrade immediately.

## Fixture and probes

The benign probe queued a task command presenting credentials. The advisory-shaped probe queued a command-bearing task unauthenticated. The fixture incremented its marker when an unauthenticated queue reached the handler.

## Measured comparison (2026-11-14 UTC)

The values after each status are the observed increases in the fixture's effect counter.

| Probe | Baseline | Declarative policy | Native module |
| --- | --- | --- | --- |
| Benign authed task queue | 200, 0 | 403, 0 | 200, 0 |
| Advisory-shaped unauth queue | 200, 1 | 403, 0 | 403, 0 |

The rule requires authentication on the task-instance family and refuses command/gadget markers. The direct broker injection is a protocol gap; broker ACLs are the durable mitigation. The durable Airflow fix is the vendor's patch.
