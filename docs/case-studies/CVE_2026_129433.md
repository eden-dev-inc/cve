# Dokploy: OS command injection in Compose backup serviceName (CVE-2026-129433)

Dokploy handles the serviceName setting for Compose backups unescaped: a low-privilege authenticated org member stores a crafted serviceName that reaches an OS command path, running arbitrary commands on the deployment host — a PaaS compromise cascading to every service it manages.

## The vulnerability

The backup configuration passes the serviceName into an OS command unquoted, so a stored crafted value executes with the host's privileges. Eden fronts the Dokploy dashboard, so the crafted configuration rides an HTTP request Eden can refuse before release.

## The Eden patch

**Tier 1 — declarative policy.** The recorded policy denies every method on the recorded fixture route and its descendants. This is a coarse rule: it also blocked the benign probe on the same route, which is the recorded false positive.

```json
{
  "version": 1,
  "profile": "http-structure-v1",
  "policy": {
    "version": 1,
    "rules": [
      {
        "scope": {
          "methods": [],
          "path": "/api/deploy",
          "descendants": true
        },
        "require": {
          "kind": "deny"
        }
      }
    ]
  }
}
```

**Tier 2 — native Rust module.** gabriel_dokploycmd_v1 waits for a complete request, matches deploy routes, and refuses bodies naming a serviceName carrying shell metacharacter markers (;, $(, backtick) — the injection shapes that reach the OS path. Clean service names continue.

```rust
const ROUTE: &[u8] = b"/api/deploy";
static MARKS: [&[u8]; 3] = [b";", b"$(", b"`"];
```

## Implement the remediation

The commands are operator examples for the recorded scope. Compare fixture routes and software selectors with the intended deployment before use. See [deployment prerequisites](../deployment.md) and the [API example](../../cve/CVE-2026-129433/http-request-filter/api.md).

1. **Prepare the target.** Verify the loaded Dokploy version against the advisory. Use a compatible Eden HTTP interlay and an authenticated operator with Configure permission. Use the recorded declaration and the linked source.
2. **Apply the declaratory policy.** Set `INTERLAY` to the target interlay UUID in the authenticated Eden CLI. Save the interlay's complete current settings, place the policy from this report in `settings.remediation`, and PATCH the full settings object with a fresh `Idempotency-Key`. Read the interlay back and confirm `remediation_status.state` is `ready`.
3. **Import and activate the native module.** Build the schema-2 archive from the linked source with the compatible SDK, verify its digest, and PUT it to the interlay's patch-packages endpoint. Import requires explicit activation: enroll the publisher key, attest the host inventory, inspect the returned configuration, obtain independent host approval, sign the typed statement, admit, and activate. Read the receipt until `serving_now` is true and the expected shards are acknowledged. Full command sequences are in the [API example](../../cve/CVE-2026-129433/http-request-filter/api.md).
4. **Verify, revoke, and restore.** Replay the benign and advisory-shaped probes and compare the backend counter. Revoke the operation and confirm the advisory-shaped request no longer succeeds (fail-closed 503); re-approve, re-admit, and reactivate a replacement operation to restore protection.

**Vendor update.** The fixed release carries the durable repair; the [advisory](https://cve.now/CVE-2026-129433) links the vendor's update instructions where available. Eden's tiers are an enforcement stopgap for a deployment that cannot upgrade immediately.

## Fixture and probes

The benign probe deployed a Compose service with a clean name. The advisory-shaped probe stored a serviceName carrying a metacharacter command. The fixture incremented its marker when an injected service name reached the command path.

## Measured comparison (2026-11-14 UTC)

The values after each status are the observed increases in the fixture's effect counter.

| Probe | Baseline | Declarative policy | Native module |
| --- | --- | --- | --- |
| Benign clean serviceName | 200, 0 | 403, 0 | 200, 0 |
| Advisory-shaped injected name | 200, 1 | 403, 0 | 403, 0 |

The rule matches raw shell metacharacters in serviceName fields on deploy routes; command encodings avoiding these markers were not exercised and are a bypass to record. The real-world path is a low-privilege org login. The durable fix is the vendor's escaping patch.

## Signed module authority

Import returned HTTP 201 with explicit activation required and signature verification deferred. Read-only inspection was refused (403) for the reader principal, admission of a tampered statement was rejected (400), and admission of an invalid signature was refused (403). The activation receipt reported the module serving on all 32 expected shards. After revocation the advisory-shaped probe received HTTP 503 (fail-closed); re-approval and reactivation restored the refusal (403, counter unchanged).
