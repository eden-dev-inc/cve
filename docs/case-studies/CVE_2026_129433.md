# Dokploy: OS command injection in Compose backup serviceName (CVE-2026-129433)

An authenticated Dokploy organization member can store a service name that injects a command when scheduled backups run. Commands can run as root and access the host through the Docker socket.

## The vulnerability

The affected versions and upgrade guidance are listed above. The Eden policy and module were tested against the HTTP fixture described below.

## Synthetic HTTP controls

**Tier 1 — declarative policy.** The recorded policy denies every method on the recorded fixture route and its descendants. This is a coarse rule: it also blocked the benign probe on the same route, which is the recorded false positive.

```json
{
  "version": 1,
  "profile": "http-structure-v1",
  "policy": {
    "version": 1,
    "rules": [
      {
        "scope": {
          "methods": [],
          "path": "/api/deploy",
          "descendants": true
        },
        "require": {
          "kind": "deny"
        }
      }
    ]
  }
}
```

**Tier 2 — native Rust module.** The rule refuses selected shell strings in a matching synthetic deployment request containing the serviceName marker.

```rust
const ROUTE: &[u8] = b"/api/deploy";
static MARKS: [&[u8]; 3] = [b";", b"$(", b"`"];
```
