# VanBlog: path traversal file read in the custom page handler (CVE-2026-129260)

A remote attacker can exploit the VanBlog custom page handler to traverse paths and access files outside the intended directory. This can expose sensitive files readable by the server process.

## The vulnerability

The affected versions and upgrade guidance are listed above. The Eden policy and module were tested against the HTTP fixture described below.

## Synthetic HTTP controls

**Tier 1 — declarative policy.** The recorded policy denies every method on the recorded fixture route and its descendants. This is a coarse rule: it also blocked the benign probe on the same route, which is the recorded false positive.

```json
{
  "version": 1,
  "profile": "http-structure-v1",
  "policy": {
    "version": 1,
    "rules": [
      {
        "scope": {
          "methods": [],
          "path": "/api/custom-page",
          "descendants": true
        },
        "require": {
          "kind": "deny"
        }
      }
    ]
  }
}
```

**Tier 2 — native Rust module.** The rule scans synthetic custom-page requests for selected path strings.

```rust
const ROUTE: &[u8] = b"/api/custom-page";
static MARKS: [&[u8]; 5] = [b"../", b"..%2f", b"%2e%2e", b"/etc/", b"file:"];
```

## Implement the remediation

**Vendor update.** The CVE record lists the `test-20261013` build as unaffected. Check with the VanBlog maintainers for a supported release containing the fix before upgrading production. Restrict untrusted access to the custom-page feature until a supported fix is available. [VanBlog releases](https://github.com/Mereithhh/vanblog/releases)

To reproduce the synthetic comparison, use the [fixture API example](../../cve/CVE-2026-129260/http-request-filter/api.md) and the synthetic controls above.

Read-only inspection was refused (403) for the reader principal, admission of a tampered statement was rejected (400), and admission of an invalid signature was refused (403).
