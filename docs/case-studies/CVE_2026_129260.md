# VanBlog: path traversal file read in the custom page handler (CVE-2026-129260)

VanBlog's Custom Page Handler resolves a caller-supplied path argument against the filesystem without confinement, letting an authenticated high-privilege caller read files outside the intended directory — server configuration and credential files included.

## The vulnerability

The custom page handler joins the path argument into a filesystem read without confining it to the intended directory, so traversal sequences escape to arbitrary files. Eden fronts the VanBlog server, so the crafted page request rides an HTTP request Eden can refuse before release.

## The Eden patch

**Tier 1 — declarative policy.** The recorded policy denies every method on the recorded fixture route and its descendants. This is a coarse rule: it also blocked the benign probe on the same route, which is the recorded false positive.

```json
{
  "version": 1,
  "profile": "http-structure-v1",
  "policy": {
    "version": 1,
    "rules": [
      {
        "scope": {
          "methods": [],
          "path": "/api/custom-page",
          "descendants": true
        },
        "require": {
          "kind": "deny"
        }
      }
    ]
  }
}
```

**Tier 2 — native Rust module.** gabriel_vanblog_v1 waits for a complete request, matches the custom-page route, and refuses targets or bodies carrying traversal or absolute-path markers (../, percent-encoded forms, /etc/, file:) — the escape shapes that reach the file read. Clean page paths continue.

```rust
const ROUTE: &[u8] = b"/api/custom-page";
static MARKS: [&[u8]; 5] = [b"../", b"..%2f", b"%2e%2e", b"/etc/", b"file:"];
```

## Implement the remediation

The commands are operator examples for the recorded scope. Compare fixture routes and software selectors with the intended deployment before use. See [deployment prerequisites](../deployment.md) and the [API example](../../cve/CVE-2026-129260/http-request-filter/api.md).

1. **Prepare the target.** Verify the loaded VanBlog version against the advisory. Use a compatible Eden HTTP interlay and an authenticated operator with Configure permission. Use the recorded declaration and the linked source.
2. **Apply the declaratory policy.** Set `INTERLAY` to the target interlay UUID in the authenticated Eden CLI. Save the interlay's complete current settings, place the policy from this report in `settings.remediation`, and PATCH the full settings object with a fresh `Idempotency-Key`. Read the interlay back and confirm `remediation_status.state` is `ready`.
3. **Import and activate the native module.** Build the schema-2 archive from the linked source with the compatible SDK, verify its digest, and PUT it to the interlay's patch-packages endpoint. Import requires explicit activation: enroll the publisher key, attest the host inventory, inspect the returned configuration, obtain independent host approval, sign the typed statement, admit, and activate. Read the receipt until `serving_now` is true and the expected shards are acknowledged. Full command sequences are in the [API example](../../cve/CVE-2026-129260/http-request-filter/api.md).
4. **Verify, revoke, and restore.** Replay the benign and advisory-shaped probes and compare the backend counter. Revoke the operation and confirm the advisory-shaped request no longer succeeds (fail-closed 503); re-approve, re-admit, and reactivate a replacement operation to restore protection.

**Vendor update.** The fixed release carries the durable repair; the [advisory](https://cve.now/CVE-2026-129260) links the vendor's update instructions where available. Eden's tiers are an enforcement stopgap for a deployment that cannot upgrade immediately.

## Fixture and probes

The benign probe loaded a custom page by its clean path. The advisory-shaped probe requested a traversal path to a system file. The fixture incremented its marker when a traversal-bearing path reached the file handler.

## Measured comparison (2026-11-14 UTC)

The values after each status are the observed increases in the fixture's effect counter.

| Probe | Baseline | Declarative policy | Native module |
| --- | --- | --- | --- |
| Benign page load | 200, 0 | 403, 0 | 200, 0 |
| Advisory-shaped traversal read | 200, 1 | 403, 0 | 403, 0 |

The rule matches raw and percent-encoded traversal, /etc/, and file: markers on the custom-page route; alternate encodings were not exercised. The real-world path is an authenticated high-privilege account — the recorded risk is file disclosure beyond the intended directory. The durable fix is the vendor's path-confinement patch.
