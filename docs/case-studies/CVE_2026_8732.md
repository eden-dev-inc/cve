# WP Maps Pro: unauthenticated privilege escalation via nopriv AJAX (CVE-2026-8732)

An unauthenticated caller can use the WP Maps Pro temporary-access action to create an administrator account and receive a login link. The plugin exposes the nonce used by the affected action to visitors.

**Patch title.** WP Maps Pro Temporary Access Guard (`wp-maps-pro-temporary-access-guard` in the registry). The [original source snapshot](https://github.com/eden-dev-inc/cve/blob/9a7217a0a882374c5ab97d74c96df9b77637f923/docs/case-studies/modules/CVE-2026-8732.rs) preserves the source available for the historical report.

## Synthetic HTTP controls

**Tier 1 — declarative policy.** The recorded policy denies every method on the recorded fixture route and its descendants. This is a coarse rule: it also blocked the benign probe on the same route, which is the recorded false positive.

```json
{
  "version": 1,
  "profile": "http-structure-v1",
  "policy": {
    "version": 1,
    "rules": [
      {
        "scope": {
          "methods": [],
          "path": "/wp-admin/admin-ajax.php",
          "descendants": true
        },
        "require": {
          "kind": "deny"
        }
      }
    ]
  }
}
```

**Tier 2 — native Rust module.** On /admin-ajax.php, the rule matches the action=wpgmp_temp_access prefix and checks for the presence of X-WPMaps-Admin.

```rust
//! refuse nopriv AJAX privilege escalation without an admin binding.
```

## Implement the remediation

**Vendor update.** Confirm the corrected release with WePlugins, then update through the WePlugins dashboard or CodeCanyon. Disable the plugin if a fix cannot be verified. Check for administrator accounts created unexpectedly. [Vendor instructions](https://www.wpmapspro.com/docs/how-to-update-the-google-maps-pro-plugin/).

The published package uses registry name `wp-maps-pro-temporary-access-guard`. Verify its own archive digest before import. Use the [fixture API example](../../cve/CVE-2026-8732/http-request-filter/api.md) to reproduce the recorded comparison. It covers the declaration, signed module activation, verification, revocation, and restoration.

## Fixture and probes

The benign probe requested temporary access presenting the admin binding. The marked probe invoked the same action requesting the admin role without any binding. The fixture incremented its marker when an unbound nopriv escalation reached the handler.

## Test scope

On /admin-ajax.php, the rule matches the action=wpgmp_temp_access prefix and checks for the presence of X-WPMaps-Admin. The fixture did not validate a WordPress nonce, create an administrator, or use a login link.

## Signed module authority

Import returned HTTP 201 with explicit activation required and signature verification deferred. Read-only inspection was refused (403) for the reader principal, admission of a tampered statement was rejected (400), and admission of an invalid signature was refused (403). The activation receipt reported the module serving on all 32 expected shards. After revocation the marked probe received HTTP 503 (fail-closed); re-approval and reactivation restored the refusal (403, counter unchanged).
