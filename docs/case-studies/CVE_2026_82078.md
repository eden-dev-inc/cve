# PaperCut: arbitrary Java execution through unapproved database drivers (CVE-2026-82078)

PaperCut MF/NG loads database drivers without checking configurable driver names against an approved list, so an attacker who can change system configuration makes the server run arbitrary Java code from its classpath with the server process's privileges. The flaw is exploited in the wild; the real-world path is a high-privilege configuration change.

## The vulnerability

The driver loader accepts arbitrary driver names, so a crafted name loads attacker-chosen classes with the server's privileges. Eden fronts the PaperCut web console, so the crafted driver write rides an HTTP request Eden can refuse before release.

## The Eden patch

**Tier 1 — declarative policy.** The recorded policy denies every method on the recorded fixture route and its descendants. This is a coarse rule: it also blocked the benign probe on the same route, which is the recorded false positive.

```json
{
  "version": 1,
  "profile": "http-structure-v1",
  "policy": {
    "version": 1,
    "rules": [
      {
        "scope": {
          "methods": [],
          "path": "/api/config",
          "descendants": true
        },
        "require": {
          "kind": "deny"
        }
      }
    ]
  }
}
```

**Tier 2 — native Rust module.** gabriel_pcdriver_v1 waits for a complete request, matches the driver configuration route, and refuses driver writes carrying path markers (.., /tmp/, file:) — the shapes that point the loader off the approved classpath. Approved driver names continue.

```rust
const ROUTE: &[u8] = b"/api/config";
static MARKS: [&[u8]; 3] = [b"..", b"/tmp/", b"file:"];
```

## Implement the remediation

The commands are operator examples for the recorded scope. Compare fixture routes and software selectors with the intended deployment before use. See [deployment prerequisites](../deployment.md) and the [API example](../../cve/CVE-2026-82078/http-request-filter/api.md).

1. **Prepare the target.** Verify the loaded PaperCut MF/NG version against the advisory. Use a compatible Eden HTTP interlay and an authenticated operator with Configure permission. Use the recorded declaration and the linked source.
2. **Apply the declaratory policy.** Set `INTERLAY` to the target interlay UUID in the authenticated Eden CLI. Save the interlay's complete current settings, place the policy from this report in `settings.remediation`, and PATCH the full settings object with a fresh `Idempotency-Key`. Read the interlay back and confirm `remediation_status.state` is `ready`.
3. **Import and activate the native module.** Build the schema-2 archive from the linked source with the compatible SDK, verify its digest, and PUT it to the interlay's patch-packages endpoint. Import requires explicit activation: enroll the publisher key, attest the host inventory, inspect the returned configuration, obtain independent host approval, sign the typed statement, admit, and activate. Read the receipt until `serving_now` is true and the expected shards are acknowledged. Full command sequences are in the [API example](../../cve/CVE-2026-82078/http-request-filter/api.md).
4. **Verify, revoke, and restore.** Replay the benign and advisory-shaped probes and compare the backend counter. Revoke the operation and confirm the advisory-shaped request no longer succeeds (fail-closed 503); re-approve, re-admit, and reactivate a replacement operation to restore protection.

**Vendor update.** The fixed release carries the durable repair; the [advisory](https://cve.now/CVE-2026-82078) links the vendor's update instructions where available. Eden's tiers are an enforcement stopgap for a deployment that cannot upgrade immediately.

## Fixture and probes

The benign probe set an approved PostgreSQL driver name. The advisory-shaped probe set a driver name carrying path markers. The fixture incremented its marker when an off-classpath driver name reached the loader.

## Measured comparison (2026-11-13 UTC)

The values after each status are the observed increases in the fixture's effect counter.

| Probe | Baseline | Declarative policy | Native module |
| --- | --- | --- | --- |
| Benign approved driver | 200, 0 | 403, 0 | 200, 0 |
| Advisory-shaped off-classpath driver | 200, 1 | 403, 0 | 403, 0 |

The rule matches path markers in driver-name writes on the config route; class names without path markers that still resolve attacker-chosen classes are a bypass to record. The real-world path is a high-privilege user. The durable fix is the vendor's allow-list patch.
