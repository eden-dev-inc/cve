# Tactical RMM: file:// link read in report template preview (CVE-2026-129165)

A user with report management permission can make Tactical RMM's preview endpoint read any server file: WeasyPrint resolves file:// links embedded in the user-supplied template_md and embeds the bytes in the returned PDF. Reading the Django SECRET_KEY — reused as the NATS password — lets that user publish run-script commands to every managed agent, turning a reporting permission into fleet-wide code execution. No fixed release is listed at disclosure time, so an exposed console stays exposed.

**Patch title.** Tactical RMM Report Preview File URL Guard (`tactical-rmm-report-preview-file-url-guard` in the registry). ## The vulnerability

WeasyPrint follows file:// links while rendering the previewed template, and the endpoint hands it user-supplied template_md, so a report author can pull arbitrary server files into the PDF — including the Django SECRET_KEY that doubles as the NATS password. Eden fronts the RMM console, so the preview request rides an HTTP request Eden can refuse before release.

## The Eden patch

**Tier 1 — declarative policy.** The recorded policy denies every method on `/reporting/templates/preview` and its descendants. This is a coarse rule: it also blocked the benign template preview, which is the recorded false positive.

```json
{ "version": 1, "profile": "http-structure-v1", "policy": { "version": 1, "rules": [ { "scope": { "methods": [], "path": "/reporting/templates/preview", "descendants": true }, "require": { "kind": "deny" } } ] } }
```

**Tier 2 — native Rust module.** `gabriel_amidaware_v1` waits for a complete request, matches targets starting with `/reporting/templates/preview`, and refuses any target or body carrying a `file:` scheme marker (raw, backslash-escaped, or percent-encoded). Ordinary markdown previews continue.

```rust
const ROUTE: &[u8] = b"/reporting/templates/preview";
static MARKS: [&[u8]; 3] = [b"file:", b"file\\:", b"file%3a"];
```

## Implement the remediation

The commands are operator examples for the recorded scope. Compare fixture routes and software selectors with the intended deployment before use. See [deployment prerequisites](../deployment.md) and the [API example](../../cve/CVE-2026-129165/http-request-filter/api.md).

1. **Prepare the target.** Verify the loaded AmidaWare Tactical RMM version against the advisory. Use a compatible Eden HTTP interlay and an authenticated operator with Configure permission. Use the recorded declaration and the linked source.
2. **Apply the declarative policy.** Set `INTERLAY` to the target interlay UUID in the authenticated Eden CLI. Save the interlay's complete current settings, place the policy from this report in `settings.remediation`, and PATCH the full settings object with a fresh `Idempotency-Key`. Read the interlay back and confirm `remediation_status.state` is `ready`.
3. **Import and activate the native module.** Build the schema-2 archive from the linked source with the compatible SDK, verify its digest, and PUT it to the interlay's patch-packages endpoint. Import requires explicit activation: enroll the publisher key, attest the host inventory, inspect the returned configuration, obtain independent host approval, sign the typed statement, admit, and activate. Read the receipt until `serving_now` is true and the expected shards are acknowledged. Full command sequences are in the [API example](../../cve/CVE-2026-129165/http-request-filter/api.md).
4. **Verify, revoke, and restore.** Replay the benign and advisory-shaped probes and compare the backend counter. Revoke the operation and confirm the marked fixture request no longer succeeds (fail-closed 503); re-approve, re-admit, and reactivate a replacement operation to restore protection.

**Vendor update.** Check the advisory and the vendor's release channel for a fix. Restrict the affected feature's exposure while a fix is unavailable. [Advisory reference](https://vul.yulun.ac.cn/20261028/tacticalrmm/)

## Fixture and probes

The benign probe posted a plain markdown template (`# Q3 Report`). The marked fixture probe embedded a `[leak](file:///etc/passwd)` link in the same field. The fixture incremented its marker when the renderer consumed a file:// target.

## Measured comparison (2026-11-13 UTC)

The values after each status are the observed increases in the fixture's effect counter.

| Probe | Baseline | Declarative policy | Native module |
| --- | --- | --- | --- |
| Benign template preview | 200, 0 | 403, 0 | 200, 0 |
| Advisory-shaped file:// template | 200, 1 | 403, 0 | 403, 0 |

The rule matches the `file:` scheme markers; other link forms (data:, absolute paths) were not exercised. The real-world preview is authenticated — the recorded risk is privilege escalation from report-manager to fleet RCE, not anonymous access.

## Signed module authority

Read-only inspection was refused (403) for the reader principal, admission of a tampered statement was rejected (400), and admission of an invalid signature was refused (403).
