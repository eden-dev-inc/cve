# UniFi OS: improper access control to unauthorized system changes (CVE-2026-34908)

Ubiquiti UniFi OS devices expose an access control flaw letting a network attacker make unauthorized changes to the affected system — the controller compromise cascades to every access point, switch, and gateway it manages.

## The vulnerability

The controller API accepts privileged changes without binding them to an authenticated session, so a network attacker administers the managed fleet. Eden fronts the controller's web interface, so the crafted request rides an HTTP request Eden can refuse before release.

## The Eden patch

**Tier 1 — declarative policy.** The recorded policy denies every method on the recorded fixture route and its descendants. This is a coarse rule: it also blocked the benign probe on the same route, which is the recorded false positive.

```json
{
  "version": 1,
  "profile": "http-structure-v1",
  "policy": {
    "version": 1,
    "rules": [
      {
        "scope": {
          "methods": [],
          "path": "/proxy/network/api",
          "descendants": true
        },
        "require": {
          "kind": "deny"
        }
      }
    ]
  }
}
```

**Tier 2 — native Rust module.** gabriel_unifi_v1 waits for a complete request, matches UniFi controller API routes, refuses traversal and command-injection markers on any method (the 34909/34910 family shapes), and refuses unbound privileged writes (POST/PUT without the controller CSRF binding — the 34908 shape). Bound and clean requests continue.

```rust
const ROUTE: &[u8] = b"/proxy/network/api";
static MARKS: [&[u8]; 8] = [b"../", b"..%2f", b"%2e%2e", b"/etc/", b"file:", b";", b"$(", b"`"];
```

## Implement the remediation

The commands are operator examples for the recorded scope. Compare fixture routes and software selectors with the intended deployment before use. See [deployment prerequisites](../deployment.md) and the [API example](../../cve/CVE-2026-34908/http-request-filter/api.md).

1. **Prepare the target.** Verify the loaded Ubiquiti UniFi OS version against the advisory. Use a compatible Eden HTTP interlay and an authenticated operator with Configure permission. Use the recorded declaration and the linked source.
2. **Apply the declaratory policy.** Set `INTERLAY` to the target interlay UUID in the authenticated Eden CLI. Save the interlay's complete current settings, place the policy from this report in `settings.remediation`, and PATCH the full settings object with a fresh `Idempotency-Key`. Read the interlay back and confirm `remediation_status.state` is `ready`.
3. **Import and activate the native module.** Build the schema-2 archive from the linked source with the compatible SDK, verify its digest, and PUT it to the interlay's patch-packages endpoint. Import requires explicit activation: enroll the publisher key, attest the host inventory, inspect the returned configuration, obtain independent host approval, sign the typed statement, admit, and activate. Read the receipt until `serving_now` is true and the expected shards are acknowledged. Full command sequences are in the [API example](../../cve/CVE-2026-34908/http-request-filter/api.md).
4. **Verify, revoke, and restore.** Replay the benign and advisory-shaped probes and compare the backend counter. Revoke the operation and confirm the advisory-shaped request no longer succeeds (fail-closed 503); re-approve, re-admit, and reactivate a replacement operation to restore protection.

**Vendor update.** The fixed release carries the durable repair; the [advisory](https://cve.now/CVE-2026-34908) links the vendor's update instructions where available. Eden's tiers are an enforcement stopgap for a deployment that cannot upgrade immediately.

## Fixture and probes

The benign probe updated a site presenting the CSRF binding. The advisory-shaped probe performed the same write without the binding. The fixture incremented its marker when an unbound write reached the controller.

## Measured comparison (2026-11-14 UTC)

The values after each status are the observed increases in the fixture's effect counter.

| Probe | Baseline | Declarative policy | Native module |
| --- | --- | --- | --- |
| Benign bound site update | 200, 0 | 403, 0 | 200, 0 |
| Advisory-shaped unbound change | 200, 1 | 403, 0 | 403, 0 |

The module enforces a CSRF-binding contract on UniFi API writes; it does not validate the token, so a forged-but-present binding passes and is a bypass to record. The recorded route family is the controller API prefix. The durable fix is the vendor's patched release.

## Signed module authority

Read-only inspection was refused (403) for the reader principal, admission of a tampered statement was rejected (400), and admission of an invalid signature was refused (403).
