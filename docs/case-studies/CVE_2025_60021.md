# Apache bRPC: unauthenticated command injection in the builtin heap service (CVE-2025-60021)

An unauthenticated caller can execute commands through Apache bRPC's builtin heap service: crafted builtin-service requests on the same port as the application run with the service's privileges. Any deployment that leaves builtin services bound to a reachable port is exposed.

**Result.** The builtin command raised the backend counter in the baseline (200, +1). The declaratory tier refused it (403, benign false positive recorded). The native module refused the builtin command (403, counter unchanged) while the benign RPC stayed HTTP 200. Recorded through Eden 1.103.0 on 2026-11-13 (UTC).

## The vulnerability

bRPC's builtin services expose heap and profiler commands on the application port; when that port is reachable, an unauthenticated caller runs builtin service commands with the process's privileges. Eden fronts the bRPC service, so the builtin request rides an HTTP request Eden can refuse before release.

## The Eden patch

**Tier 1 — declarative policy.** The recorded policy denies every method on /brpc and its descendants. This is a coarse rule: it also blocked the benign RPC, which is the recorded false positive.

```json
{
  "version": 1,
  "profile": "http-structure-v1",
  "policy": {
    "version": 1,
    "rules": [
      {
        "scope": {
          "methods": [],
          "path": "/brpc",
          "descendants": true
        },
        "require": {
          "kind": "deny"
        }
      }
    ]
  }
}
```

**Tier 2 — native Rust module.** gabriel_brpc_v1 waits for a complete request, matches targets starting with /brpc, and refuses bodies carrying a builtin-service marker together with a heap/profiler/command marker. Ordinary application RPCs continue.

```rust
if find_ignore_case(body, b"builtin").is_none() { return Ok(Decision::Continue); }
static MARKS: [&[u8]; 3] = [b"heap", b"profil", b"cmd"];
```

## Implement the remediation

The commands are operator examples for the recorded scope. Compare fixture routes and software selectors with the intended deployment before use. See [deployment prerequisites](../deployment.md) and the [API example](../../cve/CVE-2025-60021/http-request-filter/api.md).

1. **Prepare the target.** Verify the loaded Apache bRPC version against the advisory. Use a compatible Eden HTTP interlay and an authenticated operator with Configure permission. Use the recorded declaration and the linked source.
2. **Apply the declarative policy.** Set `INTERLAY` to the target interlay UUID in the authenticated Eden CLI. Save the interlay's complete current settings, place the policy from this report in `settings.remediation`, and PATCH the full settings object with a fresh `Idempotency-Key`. Read the interlay back and confirm `remediation_status.state` is `ready`.
3. **Import and activate the native module.** Build the schema-2 archive from the linked source with the compatible SDK, verify its digest, and PUT it to the interlay's patch-packages endpoint. Import requires explicit activation: enroll the publisher key, attest the host inventory, inspect the returned configuration, obtain independent host approval, sign the typed statement, admit, and activate. Read the receipt until `serving_now` is true and the expected shards are acknowledged. Full command sequences are in the [API example](../../cve/CVE-2025-60021/http-request-filter/api.md).
4. **Verify, revoke, and restore.** Replay the benign and advisory-shaped probes and compare the backend counter. Revoke the operation and confirm the advisory-shaped request no longer succeeds (fail-closed 503); re-approve, re-admit, and reactivate a replacement operation to restore protection.

**Vendor update.** See the advisory for the fixed release carries the durable fix; the [advisory](https://cve.now/CVE-2025-60021) links the vendor's update instructions where available. Eden's tiers are an enforcement stopgap for a deployment that cannot upgrade immediately.

## Fixture and probes

The benign probe posted an ordinary application Echo RPC. The advisory-shaped probe posted a builtin heap-profiling command. The fixture incremented its marker when the builtin service executed a profiler command.

## Signed module authority

Read-only inspection was refused (403) for the reader principal, admission of a tampered statement was rejected (400), and admission of an invalid signature was refused (403). After revocation the advisory-shaped probe received HTTP 503 (fail-closed); re-approval and reactivation restored the refusal.
