# Ivanti EPM: unauthenticated SQL injection in the Core (CVE-2026-121653)

A SQL injection in the Core component of Ivanti Endpoint Manager lets a remote attacker run code on the server — no login, no user interaction. An exposed EPM core is a management-plane compromise for every endpoint it administers.

## The vulnerability

Ivanti identifies SQL injection in the Endpoint Manager Core before 2024 SU8 that can lead to code execution. The Eden fixture used a SQL marker in an inventory request and counted delivery to the synthetic handler.

## The Eden patch

**Tier 1 — declarative policy.** The recorded policy denies every method on the recorded fixture route and its descendants. This is a coarse rule: it also blocked the benign probe on the same route, which is the recorded false positive.

```json
{
  "version": 1,
  "profile": "http-structure-v1",
  "policy": {
    "version": 1,
    "rules": [
      {
        "scope": {
          "methods": [],
          "path": "/core/api",
          "descendants": true
        },
        "require": {
          "kind": "deny"
        }
      }
    ]
  }
}
```

**Tier 2 — native Rust module.** gabriel_ivantiepm_v1 waits for a complete request, matches the core API route, and refuses any target or body carrying SQL injection markers (' OR, union select, 1=1). Clean inventory calls continue.

```rust
const ROUTE: &[u8] = b"/core/api";
static NEEDLES: [&[u8]; 3] = [b"' or", b"union select", b"1=1"];
```

## Implement the remediation

The commands are operator examples for the recorded scope. Compare fixture routes and software selectors with the intended deployment before use. See [deployment prerequisites](../deployment.md) and the [API example](../../cve/CVE-2026-121653/http-request-filter/api.md).

1. **Prepare the target.** Verify the loaded Ivanti Endpoint Manager version against the advisory. Use a compatible Eden HTTP interlay and an authenticated operator with Configure permission. Use the recorded declaration and the linked source.
2. **Apply the declaratory policy.** Set `INTERLAY` to the target interlay UUID in the authenticated Eden CLI. Save the interlay's complete current settings, place the policy from this report in `settings.remediation`, and PATCH the full settings object with a fresh `Idempotency-Key`. Read the interlay back and confirm `remediation_status.state` is `ready`.
3. **Import and activate the native module.** Build the schema-2 archive from the linked source with the compatible SDK, verify its digest, and PUT it to the interlay's patch-packages endpoint. Import requires explicit activation: enroll the publisher key, attest the host inventory, inspect the returned configuration, obtain independent host approval, sign the typed statement, admit, and activate. Read the receipt until `serving_now` is true and the expected shards are acknowledged. Full command sequences are in the [API example](../../cve/CVE-2026-121653/http-request-filter/api.md).
4. **Verify, revoke, and restore.** Replay the benign and advisory-shaped probes and compare the backend counter. Revoke the operation and confirm the advisory-shaped request no longer succeeds (fail-closed 503); re-approve, re-admit, and reactivate a replacement operation to restore protection.

**Vendor update.** Apply the vendor update for the installed release or model. [Advisory reference](https://hub.ivanti.com/s/article/Security-Advisory-Ivanti-Endpoint-Manager-EPM-November-2026?language=en_US)

## Fixture and probes

The benign probe posted an ordinary inventory request. The marked fixture probe injected a SQL marker into the request type. The fixture incremented its marker when injected SQL reached its query engine.

## Signed module authority

Import returned HTTP 201 with explicit activation required and signature verification deferred. Read-only inspection was refused (403) for the reader principal, admission of a tampered statement was rejected (400), and admission of an invalid signature was refused (403). The activation receipt reported the module serving on all 32 expected shards. After revocation the advisory-shaped probe received HTTP 503 (fail-closed); re-approval and reactivation restored the refusal (403, counter unchanged).
