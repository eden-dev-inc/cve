# Plex Media Server: URL injection into plugin function calls via searchOne (CVE-2026-96654)

Plex Media Server before 1.43.3.10861 does not neutralize URL values included in its searchOne parameter, letting an attacker call functions in other plugins and supply their parameters — crossing plugin trust boundaries inside the server.

## The vulnerability

searchOne forwards a URL value into plugin function dispatch without neutralization, so a caller crosses plugin trust boundaries and invokes another plugin's functions with chosen parameters. Eden fronts the media server, so the injected URL rides an HTTP request Eden can refuse.

## The Eden patch

**Tier 1 — declarative policy.** The recorded policy denies every method on the plugin search route and its descendants. This blocks every plugin search, benign or not (the recorded false positive).

```json
{
  "version": 1,
  "profile": "http-structure-v1",
  "policy": {
    "version": 1,
    "rules": [
      {
        "scope": {
          "methods": [],
          "path": "/plugins",
          "descendants": true
        },
        "require": {
          "kind": "deny"
        }
      }
    ]
  }
}
```

**Tier 2 — native Rust module.** gabriel_plexplugin_v1 waits for a complete request, matches targets starting with the plugin route, and refuses a searchOne query parameter that carries a scheme-bearing URL (://, percent-encoded forms). Plain search terms continue.

```rust
static SCHEMES: [&[u8]; 3] = [b"://", b"%3a%2f%2f", b"%3a//"];
```

## Implement the remediation

The commands are operator examples for the recorded scope. Compare fixture routes and software selectors with the intended deployment before use. See [deployment prerequisites](../deployment.md) and the [API example](../../cve/CVE-2026-96654/http-request-filter/api.md).

1. **Prepare the target.** Verify the loaded Plex Media Server version against the advisory. Use a compatible Eden HTTP interlay and an authenticated operator with Configure permission. Use the recorded declaration and the linked source.
2. **Apply the declarative policy.** Set `INTERLAY` to the target interlay UUID in the authenticated Eden CLI. Save the interlay's complete current settings, place the policy from this report in `settings.remediation`, and PATCH the full settings object with a fresh `Idempotency-Key`. Read the interlay back and confirm `remediation_status.state` is `ready`.
3. **Import and activate the native module.** Build the schema-2 archive from the linked source with the compatible SDK, verify its digest, and PUT it to the interlay's patch-packages endpoint. Import requires explicit activation: enroll the publisher key, attest the host inventory, inspect the returned configuration, obtain independent host approval, sign the typed statement, admit, and activate. Read the receipt until `serving_now` is true and the expected shards are acknowledged. Full command sequences are in the [API example](../../cve/CVE-2026-96654/http-request-filter/api.md).
4. **Verify, revoke, and restore.** Replay the benign and advisory-shaped probes and compare the backend counter. Revoke the operation and confirm the advisory-shaped request no longer succeeds (fail-closed 503); re-approve, re-admit, and reactivate a replacement operation to restore protection.

**Vendor update.** Plex Media Server 1.43.3.10861 carries the durable fix; the [advisory](https://cve.now/CVE-2026-96654) links the vendor's update instructions where available. Eden's tiers are an enforcement stopgap for a deployment that cannot upgrade immediately.

## Fixture and probes

The benign probe searched for a movie title. The advisory-shaped probe set searchOne to a plugin URL. The fixture incremented its marker when a scheme-bearing URL reached its plugin dispatcher.

## Measured comparison (2026-11-13 UTC)

The values after each status are the observed increases in the fixture's effect counter.

| Probe | Baseline | Declarative policy | Native module |
| --- | --- | --- | --- |
| Benign title search | 200, 0 | 403, 0 | 200, 0 |
| Advisory-shaped plugin URL | 200, 1 | 403, 0 | 403, 0 |

The rule matches scheme-bearing URL markers (raw and percent-encoded) in the searchOne parameter on the plugin route; parameters that carry indirection without a URL scheme were not exercised.

## Signed module authority

Import returned HTTP 201 with explicit activation required and signature verification deferred. Read-only inspection was refused (403) for the reader principal, admission of a tampered statement was rejected (400), and admission of an invalid signature was refused (403). The activation receipt reported the module serving on all 32 expected shards. After revocation the advisory-shaped probe received HTTP 503 (fail-closed); re-approval and reactivation restored the refusal (403, counter unchanged).
