# Kendo UI for jQuery: XSS in the Chart shared tooltip (CVE-2026-124697)

[CVE advisory record](https://cve.now/CVE-2026-124697) · [Vendor advisory](https://www.telerik.com/kendo-jquery-ui/documentation/knowledge-base/kb-security-kendo-chart-shared-tooltip-xss-cve-2026-124697) · [Module source](modules/gabriel_kendochart_v1.rs)

**Result.** The marked request reached the backend in the baseline and raised its counter. The native rule refused that request with HTTP 403 and preserved HTTP 200 for the benign probe. The synthetic fixture ran through Eden 1.103.0 on November 12, 2026 (UTC).

## The vulnerability

The Chart shared tooltip interpolates category and series-name values into HTML. If an application accepts those values from an untrusted dataset, displaying a shared tooltip can execute script in the browser. The advisory concerns a shared tooltip fed by series metadata.

Progress verified affected releases at least as far back as 2016.2.607 through 2026.3.1015. The fix is in 2026.4.1111. The CVE record reports a CVSS base score of **7.1**.

## The Eden patch

**Tier 1 — declarative policy.** The recorded policy denies requests to `/kendo-ui/chart` and its descendants. The empty method list leaves the deny unrestricted by HTTP method. This is a coarse rule and blocked the benign probe on the same path.

```json
{
  "version": 1,
  "profile": "http-structure-v1",
  "policy": {
    "version": 1,
    "rules": [
      {
        "scope": {
          "methods": [],
          "path": "/kendo-ui/chart",
          "descendants": true
        },
        "require": {
          "kind": "deny"
        }
      }
    ]
  }
}
```

**Tier 2 — native Rust module.** `gabriel_kendochart_v1` waits for the request to be complete, checks whether the request target starts with `/kendo-ui/chart`, and looks for any configured marker in the body. The substring comparison is ASCII case-insensitive. Outside that prefix or without a marker, the module returns `Continue`. The shown lines are excerpts from the linked source.

```rust
const ROUTE: &[u8] = b"/kendo-ui/chart";
static NEEDLES: [&[u8]; 2] = [b"<script", b"onerror="];
```

```rust
NEEDLES.iter().any(|n| find_ignore_case(body, n).is_some()) && return Ok(Decision::Refuse);
```

## Fixture and probes

The fixture was a synthetic HTTP handler behind Eden. It answered the probes and kept a separate counter that increased when the handler recognized its marker bytes. The counter measures a fixture effect. An HTTP 200 from the baseline does not by itself establish that the counter moved.

**Request.** `POST /kendo-ui/chart/tooltip` for the benign probe and the marked probe.

The fixture posted an ordinary tooltip label and a script-bearing label with an additional event-handler marker. The synthetic handler recorded the marker independently of the HTTP 200 response.

## Test scope

The rule scans the HTTP body carrying tooltip data. Data loaded through another route or assembled client-side can bypass this enforcement point. The test did not bind the payload to a real Chart series or render a tooltip. The prefix match also includes sibling paths with the same leading bytes.
