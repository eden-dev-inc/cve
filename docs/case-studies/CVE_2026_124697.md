# Kendo UI for jQuery: XSS in the Chart shared tooltip (CVE-2026-124697)

[Advisory record](https://cve.now/CVE-2026-124697)

**Status.** Two-tier request-filter comparison against Eden 1.103.0 using a synthetic HTTP fixture.

[Module source](modules/gabriel_kendochart_v1.rs)

## The vulnerability

The shared tooltip can render a category or series name as HTML. Attacker-controlled chart data may execute script when the tooltip opens. Progress fixed the issue in 2026.4.1111.

## The Eden patch

**Tier 1 — declarative policy.** Deny all requests under the fixture prefix `/kendo-ui/chart`, including benign requests.

**Tier 2 — native Rust module.** Match the fixture route and refuse bodies containing any of the module's configured markers.

## Measured comparison (2026-11-12 UTC)

| Configuration | Benign request | Attack fixture |
| --- | --- | --- |
| Baseline | HTTP 200 | HTTP 200, backend marker recorded |
| Tier 1 route deny | HTTP 403 | HTTP 403 |
| Tier 2 native module | HTTP 200 | HTTP 403, backend marker absent |

## Signed module authority

The module was imported for explicit activation. Both expected shards acknowledged activation. Reader inspection, a tampered statement and an invalid signature were rejected. After revocation the same request received HTTP 503. Re-approval and reactivation restored HTTP 403.

## Test scope

The test exercised a synthetic HTTP route and recorded a harmless backend marker. Browser rendering and vendor component behavior are outside the tested scope.

The measurements cover the supplied fixture probes. Alternate routes, encodings, and other bypasses remain untested.
