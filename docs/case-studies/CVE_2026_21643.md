# FortiClientEMS 7.4.4: SQL injection (CVE-2026-21643)

[CVE advisory record](https://cve.now/CVE-2026-21643) · [Vendor advisory](https://fortiguard.fortinet.com/psirt/FG-IR-25-1142) · [Module source](modules/gabriel_forticlient_v1.rs)

**Result.** The marked request reached the backend in the baseline and raised its counter. The native rule refused that request with HTTP 403 and preserved HTTP 200 for the benign probe. The synthetic fixture ran through Eden 1.103.0 on November 12, 2026 (UTC).

## The vulnerability

The affected FortiClientEMS release can process crafted unauthenticated HTTP requests as part of a SQL operation. The vendor describes unauthorized command or code execution as a possible consequence, so authentication at the management interface does not remove the exposure described by the advisory.

Fortinet lists 7.4.4 as affected and 7.4.5 as the fix for the 7.4 series. The CVE record reports a CVSS base score of **9.1**.

## The Eden patch

**Tier 1 — declarative policy.** The recorded policy denies requests to `/api/v2/clients` and its descendants. The empty method list leaves the deny unrestricted by HTTP method. This is a coarse rule and blocked the benign probe on the same path.

```json
{
  "version": 1,
  "profile": "http-structure-v1",
  "policy": {
    "version": 1,
    "rules": [
      {
        "scope": {
          "methods": [],
          "path": "/api/v2/clients",
          "descendants": true
        },
        "require": {
          "kind": "deny"
        }
      }
    ]
  }
}
```

**Tier 2 — native Rust module.** `gabriel_forticlient_v1` waits for the request to be complete, checks whether the request target starts with `/api/v2/clients`, and looks for any configured marker in the body. The substring comparison is ASCII case-insensitive. Outside that prefix or without a marker, the module returns `Continue`. The shown lines are excerpts from the linked source.

```rust
const ROUTE: &[u8] = b"/api/v2/clients";
static NEEDLES: [&[u8]; 3] = [b"' OR ", b"union select", b"1=1"];
```

```rust
NEEDLES.iter().any(|n| find_ignore_case(body, n).is_some()) && return Ok(Decision::Refuse);
```

## Fixture and probes

The fixture was a synthetic HTTP handler behind Eden. It answered the probes and kept a separate counter that increased when the handler recognized its marker bytes. The counter measures a fixture effect. An HTTP 200 from the baseline does not by itself establish that the counter moved.

**Request.** `POST /api/v2/clients/search` for the benign probe and the marked probe.

The benign fixture searched for active clients. The second sent a SQL predicate marker in the filter value. The backend incremented a counter when it received the matching bytes.

## Signed module authority

The module import returned HTTP 201 and required explicit activation. Signature verification was deferred at import. Read-only inspection returned HTTP 403, admission with a tampered statement returned HTTP 400, and admission with an invalid signature returned HTTP 403. ## Test scope

The client-search path is synthetic. The actual FortiClientEMS handler and SQL execution were outside the run. The filter scans the complete request body without associating the marker with a specific parameter or SQL context.
