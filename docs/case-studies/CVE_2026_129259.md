# VanBlog: stored XSS via the image upload endpoint (CVE-2026-129259)

A remote attacker can inject script through the affected VanBlog image upload handler. If the script reaches a viewer's browser, it can act with the privileges of that browser session.

## The vulnerability

The affected versions and upgrade guidance are listed above. The Eden policy and module were tested against the HTTP fixture described below.

## Synthetic HTTP controls

**Tier 1 — declarative policy.** The recorded policy denies every method on the recorded fixture route and its descendants. This is a coarse rule: it also blocked the benign probe on the same route, which is the recorded false positive.

```json
{
  "version": 1,
  "profile": "http-structure-v1",
  "policy": {
    "version": 1,
    "rules": [
      {
        "scope": {
          "methods": [],
          "path": "/api/img/upload",
          "descendants": true
        },
        "require": {
          "kind": "deny"
        }
      }
    ]
  }
}
```

**Tier 2 — native Rust module.** The rule scans synthetic image-upload requests for selected HTML markers.

```rust
const ROUTE: &[u8] = b"/api/img/upload";
static MARKS: [&[u8]; 4] = [b"<script", b"<img", b"<iframe", b"onerror="];
```

## Implement the remediation

**Vendor update.** The advisory does not identify a fixed release. Disable untrusted access to the VanBlog image upload endpoint until the maintainers identify a production fix. After upgrading, verify in staging that uploaded content cannot execute script when viewed. [VanBlog releases](https://github.com/Mereithhh/vanblog/releases)

To reproduce the synthetic comparison, use the [fixture API example](../../cve/CVE-2026-129259/http-request-filter/api.md) and the synthetic controls above.

## Fixture and probes

The ordinary probe used a clean image name. The marked request supplied an HTML marker and the fixture counted its delivery.

## Signed module authority

Import returned HTTP 201 with explicit activation required and signature verification deferred. Read-only inspection was refused (403) for the reader principal, admission of a tampered statement was rejected (400), and admission of an invalid signature was refused (403). The activation receipt reported the module serving on all 32 expected shards. After revocation the marked fixture probe received HTTP 503 (fail-closed); re-approval and reactivation restored the refusal (403, counter unchanged).
