# Linear eMerge E3: unauthenticated command injection (CVE-2019-7256)

Linear eMerge E3-Series access-control devices accept injected operating-system commands from the network without authentication. The flaw sits on CISA's exploited-in-the-wild catalog, and a device that opens doors on command is a physical-security compromise, not just an IT one.

## The vulnerability

The device's web stack passes unauthenticated parameters into command execution, so a remote caller runs commands with the device's privileges. Eden fronts the device interface, so the injected parameter rides an HTTP request Eden can refuse.

## The Eden patch

**Tier 1 — declarative policy.** The recorded policy denies every method on the device login route and its descendants. This blocks every login, benign or not (the recorded false positive) — an emergency posture on an access-control device.

```json
{
  "version": 1,
  "profile": "http-structure-v1",
  "policy": {
    "version": 1,
    "rules": [
      {
        "scope": {
          "methods": [],
          "path": "/login",
          "descendants": true
        },
        "require": {
          "kind": "deny"
        }
      }
    ]
  }
}
```

**Tier 2 — native Rust module.** gabriel_emerge_v1 waits for a complete request, matches targets starting with the device login route, and refuses bodies carrying shell metacharacter markers (;, $(, backtick). Clean credential bodies continue.

```rust
const ROUTE: &[u8] = b"/login";
static MARKS: [&[u8]; 3] = [b";", b"$(", b"`"];
```

## Implement the remediation

The commands are operator examples for the recorded scope. Compare fixture routes and software selectors with the intended deployment before use. See [deployment prerequisites](../deployment.md) and the [API example](../../cve/CVE-2019-7256/http-request-filter/api.md).

1. **Prepare the target.** Verify the loaded Linear eMerge E3-Series version against the advisory. Use a compatible Eden HTTP interlay and an authenticated operator with Configure permission. Use the recorded declaration and the linked source.
2. **Apply the declarative policy.** Set `INTERLAY` to the target interlay UUID in the authenticated Eden CLI. Save the interlay's complete current settings, place the policy from this report in `settings.remediation`, and PATCH the full settings object with a fresh `Idempotency-Key`. Read the interlay back and confirm `remediation_status.state` is `ready`.
3. **Import and activate the native module.** Build the schema-2 archive from the linked source with the compatible SDK, verify its digest, and PUT it to the interlay's patch-packages endpoint. Import requires explicit activation: enroll the publisher key, attest the host inventory, inspect the returned configuration, obtain independent host approval, sign the typed statement, admit, and activate. Read the receipt until `serving_now` is true and the expected shards are acknowledged. Full command sequences are in the [API example](../../cve/CVE-2019-7256/http-request-filter/api.md).
4. **Verify, revoke, and restore.** Replay the benign and advisory-shaped probes and compare the backend counter. Revoke the operation and confirm the advisory-shaped request no longer succeeds (fail-closed 503); re-approve, re-admit, and reactivate a replacement operation to restore protection.

**Vendor update.** See the advisory for the fixed release carries the durable fix; the [advisory](https://cve.now/CVE-2019-7256) links the vendor's update instructions where available. Eden's tiers are an enforcement stopgap for a deployment that cannot upgrade immediately.

## Fixture and probes

The benign probe posted an ordinary credential login. The advisory-shaped probe appended a shell command to the username. The fixture incremented its marker when injected commands reached its shell.

## Measured comparison (2026-11-13 UTC)

The values after each status are the observed increases in the fixture's effect counter.

| Probe | Baseline | Declarative policy | Native module |
| --- | --- | --- | --- |
| Benign credential login | 200, 0 | 403, 0 | 200, 0 |

The advisory does not publish the vulnerable route; the fixture delivers the injection shape on a device login route and labels that honestly. The marker set covers ;, $( and backtick; metacharacter-free command paths were not exercised.

## Signed module authority

Import returned HTTP 201 with explicit activation required and signature verification deferred. Read-only inspection was refused (403) for the reader principal, admission of a tampered statement was rejected (400), and admission of an invalid signature was refused (403). The activation receipt reported the module serving on all 32 expected shards. After revocation the advisory-shaped probe received HTTP 503 (fail-closed); re-approval and reactivation restored the refusal (403, counter unchanged).
