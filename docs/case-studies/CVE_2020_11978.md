# Airflow: authenticated command execution via example-DAG parameters (CVE-2020-11978)

Older Apache Airflow releases let an authenticated user run arbitrary commands with the webserver's privileges through the example DAGs' unsanitized parameters. The flaw is exploited in the wild, and the trigger route is the same one every legitimate DAG run uses.

## The vulnerability

The example DAGs interpolate caller-supplied trigger parameters into shell commands unquoted, so an authenticated user injects OS commands. Eden fronts the Airflow webserver, so the trigger request rides an HTTP request Eden can refuse before release.

## The Eden patch

**Tier 1 — declaratory policy.** The recorded policy denies every method on the recorded route family and its descendants. This is a coarse rule: it also blocked the benign probe on the same route, which is the recorded false positive.

```json
{
  "version": 1,
  "profile": "http-structure-v1",
  "policy": {
    "version": 1,
    "rules": [
      {
        "scope": {
          "methods": [],
          "path": "/api/v1/dags",
          "descendants": true
        },
        "require": {
          "kind": "deny"
        }
      }
    ]
  }
}
```

**Tier 2 — native Rust module.** gabriel_aftrigger_v1 waits for a complete request, matches POSTs on the dagRuns trigger route, and refuses bodies carrying shell metacharacter or SQL markers (;, $(, backtick, ' OR, union select) — the injection family the example-DAG and parameter flaws expose. Clean trigger bodies continue.

```rust
static MARKS: [&[u8]; 5] = [b";", b"$(", b"`", b"' or", b"union select"];
```

## Implement the remediation

The commands are operator examples for the recorded scope. Compare fixture routes and software selectors with the intended deployment before use. See [deployment prerequisites](../deployment.md) and the [API example](../../cve/CVE-2020-11978/http-request-filter/api.md).

1. **Prepare the target.** Verify the loaded Apache Airflow (example DAGs) version against the advisory. Use a compatible Eden HTTP interlay and an authenticated operator with Configure permission.
2. **Apply the declaratory policy.** Set `INTERLAY` to the target interlay UUID in the authenticated Eden CLI. Save the interlay's complete current settings, place the policy from this report in `settings.remediation`, and PATCH the full settings object with a fresh `Idempotency-Key`. Read the interlay back and confirm `remediation_status.state` is `ready`.
3. **Import and activate the native module.** Build the schema-2 archive from the linked source with the compatible SDK, verify its digest, and PUT it to the interlay's patch-packages endpoint. Import requires explicit activation: enroll the publisher key, attest the host inventory, inspect the returned configuration, obtain independent host approval, sign the typed statement, admit, and activate. Read the receipt until `serving_now` is true and the expected shards are acknowledged.
4. **Verify, revoke, and restore.** Replay the benign and advisory-shaped probes and compare the backend counter. Revoke the operation and confirm the advisory-shaped request no longer succeeds (fail-closed 503); re-approve, re-admit, and reactivate a replacement operation to restore protection.

**Vendor update.** The fixed release carries the durable repair; the [advisory](https://cve.now/CVE-2020-11978) links the vendor's update instructions where available. Eden's tiers are an enforcement stopgap for a deployment that cannot upgrade immediately.

## Fixture and probes

The benign probe triggered a DAG run with a clean parameter value. The advisory-shaped probe appended a metacharacter command to the same parameter. The fixture incremented its marker when injected parameters reached the command construction.

## Measured comparison (2026-11-14 UTC)

The values after each status are the observed increases in the fixture's effect counter.

| Probe | Baseline | Declarative policy | Native module |
| --- | --- | --- | --- |
| Benign clean trigger | 200, 0 | 403, 0 | 200, 0 |
| Advisory-shaped injected trigger | 200, 1 | 403, 0 | 403, 0 |

The rule matches raw metacharacters in trigger bodies; parameter values legitimately containing these characters are false-positived (recorded trade-off). This module covers the whole trigger-param family (CVE-2022-24288, CVE-2022-40127, CVE-2023-22884, CVE-2026-42252). The durable fix is the vendor's sanitization patch.
