# Rclone: unauthenticated options/set enables auth bypass and RCE (CVE-2026-41176)

Rclone exposes the RC (remote control) endpoint options/set without authentication by default in affected configurations: an unauthenticated network caller rewrites runtime options — including the auth configuration itself — leading to auth bypass and, through options that reach exec paths, remote code execution.

## The vulnerability

The RC server's options/set endpoint mutates runtime configuration without an authentication check, so an unauthenticated caller rewrites auth options and takes the sync daemon over. Eden fronts the RC listener, so the unauthenticated options write rides an HTTP request Eden can refuse before release.

## The Eden patch

**Tier 1 — declarative policy.** The recorded policy denies every method on the recorded fixture route and its descendants. This is a coarse rule: it also blocked the benign probe on the same route, which is the recorded false positive.

```json
{
  "version": 1,
  "profile": "http-structure-v1",
  "policy": {
    "version": 1,
    "rules": [
      {
        "scope": {
          "methods": [],
          "path": "/rc/options/set",
          "descendants": true
        },
        "require": {
          "kind": "deny"
        }
      }
    ]
  }
}
```

**Tier 2 — native Rust module.** gabriel_rclone_v1 waits for a complete request, matches the RC options/set endpoint by path, and refuses unauthenticated POSTs to it — the unbound options-write shape. Authenticated RC calls continue.

```rust
//! refuse unauthenticated posts to the RC options/set endpoint.
```

## Implement the remediation

The commands are operator examples for the recorded scope. Compare fixture routes and software selectors with the intended deployment before use. See [deployment prerequisites](../deployment.md) and the [API example](../../cve/CVE-2026-41176/http-request-filter/api.md).

1. **Prepare the target.** Verify the loaded Rclone version against the advisory. Use a compatible Eden HTTP interlay and an authenticated operator with Configure permission. Use the recorded declaration and the linked source.
2. **Apply the declaratory policy.** Set `INTERLAY` to the target interlay UUID in the authenticated Eden CLI. Save the interlay's complete current settings, place the policy from this report in `settings.remediation`, and PATCH the full settings object with a fresh `Idempotency-Key`. Read the interlay back and confirm `remediation_status.state` is `ready`.
3. **Import and activate the native module.** Build the schema-2 archive from the linked source with the compatible SDK, verify its digest, and PUT it to the interlay's patch-packages endpoint. Import requires explicit activation: enroll the publisher key, attest the host inventory, inspect the returned configuration, obtain independent host approval, sign the typed statement, admit, and activate. Read the receipt until `serving_now` is true and the expected shards are acknowledged. Full command sequences are in the [API example](../../cve/CVE-2026-41176/http-request-filter/api.md).
4. **Verify, revoke, and restore.** Replay the benign and advisory-shaped probes and compare the backend counter. Revoke the operation and confirm the advisory-shaped request no longer succeeds (fail-closed 503); re-approve, re-admit, and reactivate a replacement operation to restore protection.

**Vendor update.** The fixed release carries the durable repair; the [advisory](https://cve.now/CVE-2026-41176) links the vendor's update instructions where available. Eden's tiers are an enforcement stopgap for a deployment that cannot upgrade immediately.

## Fixture and probes

The benign probe set an option with a valid RC bearer token. The advisory-shaped probe performed the same write with no Authorization header. The fixture incremented its marker when an unauthenticated options write reached the RC handler.

## Measured comparison (2026-11-14 UTC)

The values after each status are the observed increases in the fixture's effect counter.

| Probe | Baseline | Declarative policy | Native module |
| --- | --- | --- | --- |
| Benign authed option set | 200, 0 | 403, 0 | 200, 0 |
| Advisory-shaped unauth options write | 200, 1 | 403, 0 | 403, 0 |

The module enforces an authentication-presence contract on the options/set path; it does not validate the credential, so a forged-but-present Authorization passes and is a bypass to record. The durable fix is the vendor's patch (authentication on the RC endpoint).
