# FortiManager and FortiAnalyzer: unauthenticated code execution via output encoding (CVE-2026-126170)

An unauthenticated remote caller can run code on FortiManager, FortiAnalyzer, their Cloud editions, or FortiAnalyzer-BigData through an output-encoding flaw, sending a specially crafted HTTP request. Public exploit code is available, so an exposed management interface should be treated as compromisable.

## The vulnerability

The management products decode crafted byte sequences in a way that escapes into code execution, reachable unauthenticated over HTTP. Eden fronts the management interface, so the crafted request rides an HTTP request Eden can refuse before release.

## The Eden patch

**Tier 1 — declarative policy.** The recorded policy denies every method on the recorded fixture route and its descendants. This is a coarse rule: it also blocked the benign probe on the same route, which is the recorded false positive.

```json
{
  "version": 1,
  "profile": "http-structure-v1",
  "policy": {
    "version": 1,
    "rules": [
      {
        "scope": {
          "methods": [],
          "path": "/api/v2",
          "descendants": true
        },
        "require": {
          "kind": "deny"
        }
      }
    ]
  }
}
```

**Tier 2 — native Rust module.** gabriel_faencode_v1 waits for a complete request, matches targets starting with the v2 API route, and refuses bodies carrying a NUL byte or percent-encoded binary craft markers (%00, %ff) — the malformed-encoding shapes the advisory describes.

```rust
const ROUTE: &[u8] = b"/api/v2";
// refuse NUL bytes and %00/%ff craft markers
```

## Implement the remediation

The commands are operator examples for the recorded scope. Compare fixture routes and software selectors with the intended deployment before use. See [deployment prerequisites](../deployment.md) and the [API example](../../cve/CVE-2026-126170/http-request-filter/api.md).

1. **Prepare the target.** Verify the loaded Fortinet FortiManager / FortiAnalyzer version against the advisory. Use a compatible Eden HTTP interlay and an authenticated operator with Configure permission. Use the recorded declaration and the linked source.
2. **Apply the declaratory policy.** Set `INTERLAY` to the target interlay UUID in the authenticated Eden CLI. Save the interlay's complete current settings, place the policy from this report in `settings.remediation`, and PATCH the full settings object with a fresh `Idempotency-Key`. Read the interlay back and confirm `remediation_status.state` is `ready`.
3. **Import and activate the native module.** Build the schema-2 archive from the linked source with the compatible SDK, verify its digest, and PUT it to the interlay's patch-packages endpoint. Import requires explicit activation: enroll the publisher key, attest the host inventory, inspect the returned configuration, obtain independent host approval, sign the typed statement, admit, and activate. Read the receipt until `serving_now` is true and the expected shards are acknowledged. Full command sequences are in the [API example](../../cve/CVE-2026-126170/http-request-filter/api.md).
4. **Verify, revoke, and restore.** Replay the benign and advisory-shaped probes and compare the backend counter. Revoke the operation and confirm the advisory-shaped request no longer succeeds (fail-closed 503); re-approve, re-admit, and reactivate a replacement operation to restore protection.

**Vendor update.** The fixed release carries the durable repair; the [advisory](https://cve.now/CVE-2026-126170) links the vendor's update instructions where available. Eden's tiers are an enforcement stopgap for a deployment that cannot upgrade immediately.

## Fixture and probes

The benign probe posted an ordinary monitor query. The advisory-shaped probe posted a body carrying percent-encoded NUL and 0xff markers. The fixture incremented its marker when a crafted encoding reached its decoder.

## Measured comparison (2026-11-13 UTC)

The values after each status are the observed increases in the fixture's effect counter.

| Probe | Baseline | Declarative policy | Native module |
| --- | --- | --- | --- |
| Benign monitor query | 200, 0 | 403, 0 | 200, 0 |

The rule refuses NUL bytes and the recorded percent-encoded binary markers on the v2 API route; other malformed-encoding shapes were not exercised. The exact vulnerable handler is appliance-internal; the fixture delivers the craft shape on a representative API path.

## Signed module authority

Import returned HTTP 201 with explicit activation required and signature verification deferred. Read-only inspection was refused (403) for the reader principal, admission of a tampered statement was rejected (400), and admission of an invalid signature was refused (403). After revocation the advisory-shaped probe received HTTP 503 (fail-closed); re-approval and reactivation restored the refusal (403, counter unchanged).
