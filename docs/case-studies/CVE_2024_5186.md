# privateGPT SSRF via file upload (CVE-2024-5186)

[Source and API bundle](../../cve/CVE-2024-5186/README.md)

*[cve.now](https://cve.now/CVE-2024-5186) entry. Product: privategpt (lab:
`gabriel-privategpt`).*

Eden terminates the HTTP connection to the affected product, evaluates a
declarative policy and — in tier 2 — a separately compiled native Rust module
under signed module authority, before any byte reaches the application. It does
**not** patch the affected component; the vendor's fixed release remains the
durable repair.

**Status: Remediated (tier 1 + tier 2), live-proven 2026-11-11T16:46:38Z on the
installed `eden-product-release:1.103.0` lab container.**

## The vulnerability

The privateGPT file-upload path fetches a caller-supplied URL, so a crafted
upload can drive the server to internal services (metadata endpoints,
loopback agents). The fixture (`fixtures9.py`, `make_pgpt`) reproduces the
delivery shape: an upload whose `url` member points at
`http://169.254.169.254/credentials` records an internal-fetch mark.

## The Eden patch

**Tier 1 — declarative policy (blunt, fail-closed):** deny every request under
`/file/upload`, legitimate uploads included — false positives measured below.

**Tier 2 — native Rust module `gabriel_pgpt_v1` (surgical):** refuses upload
bodies whose URL carries loopback/link-local markers (`169.254`, `127.0.0.1`,
`localhost`, `::1`); relative-path uploads and ordinary external URLs pass
unchanged.

## Authority lifecycle and negatives

Import 201, `activation: explicit_required`; publisher `enroll_key`, host
`inventory` + `approve`, reader `inspect` refused 403; tampered-statement admit
400; invalid-signature admit 403; `admit` prepared (not serving), `activate`
→ receipt `serving_now`, applied shards **2/2**. Revoke → the identical attack
gets **503** (fail-closed); re-approve + re-activate → 403 again. All recorded
in the evidence JSON.

## Honest scope

The fixture reproduces the delivery shape, not the full privateGPT upload
surface. Bypass variants (redirects, alternate URL fields, DNS rebinding) are
not bypass-tested; the rule is a lab-grade partial. Module binary SHA-256
`a16c2caa…`, source `modules/gabriel_pgpt_v1.rs`.
