# Plesk Obsidian: cross-subscription disclosure in GoAccess statistics (CVE-2026-82977)

[CVE advisory record](https://cve.now/CVE-2026-82977) · [Vendor advisory](https://support.plesk.com/hc/en-us/articles/44915912496535-Vulnerability-CVE-2026-82977-Information-disclosure-in-Plesk-for-Linux-web-statistics) · [Module source](modules/gabriel_pleskstat_v1.rs)

**Result.** The marked request reached the backend in the baseline and raised its counter. The native rule refused that request with HTTP 403 and preserved HTTP 200 for the benign probe. The synthetic fixture ran through Eden 1.103.0 on November 12, 2026 (UTC).

## The vulnerability

Plesk’s GoAccess integration generates web statistics for hosted subscriptions. The security boundary is between subscriptions on the same host. The advisory identifies cross-subscription information disclosure in affected Plesk Obsidian for Linux releases.

The advisory lists 18.0.77–18.0.81.7 and 18.0.82–18.0.82.2 as affected. Consult the Plesk advisory for release-specific remediation. The CVE record reports a CVSS base score of **8.4**.

## The Eden patch

**Tier 1 — declarative policy.** The recorded policy denies requests to `/goaccess` and its descendants. The empty method list leaves the deny unrestricted by HTTP method. This is a coarse rule and blocked the benign probe on the same path.

```json
{
  "version": 1,
  "profile": "http-structure-v1",
  "policy": {
    "version": 1,
    "rules": [
      {
        "scope": {
          "methods": [],
          "path": "/goaccess",
          "descendants": true
        },
        "require": {
          "kind": "deny"
        }
      }
    ]
  }
}
```

**Tier 2 — native Rust module.** `gabriel_pleskstat_v1` waits for the request to be complete, checks whether the request target starts with `/goaccess`, and looks for any configured marker in the body. The substring comparison is ASCII case-insensitive. Outside that prefix or without a marker, the module returns `Continue`. The shown lines are excerpts from the linked source.

```rust
const ROUTE: &[u8] = b"/goaccess";
static NEEDLES: [&[u8]; 2] = [b"/var/log/", b"../"];
```

```rust
NEEDLES.iter().any(|n| find_ignore_case(body, n).is_some()) && return Ok(Decision::Refuse);
```

## Fixture and probes

The fixture was a synthetic HTTP handler behind Eden. It answered the probes and kept a separate counter that increased when the handler recognized its marker bytes. The counter measures a fixture effect. An HTTP 200 from the baseline does not by itself establish that the counter moved.

**Request.** `POST /goaccess/stats` for the benign probe and the marked probe.

The benign fixture body requested a weekly report. The second supplied a log-path string and parent directory fragments. The synthetic handler recorded those bytes without reading any log or checking account permissions.

## Test scope

The module scans request bodies for path fragments. The advisory’s cross-subscription authorization failure remains unverified. A correct-looking request to a different subscription is not something this byte matcher can distinguish. Legitimate report configuration containing a log path can also match.
