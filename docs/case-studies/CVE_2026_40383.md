# Joomla core: local file inclusion in the HTMLView layout parameter (CVE-2026-40383)

Joomla’s HTMLView layout parameter can be used for local file inclusion. The flaw exposes files the server process can read and that the application would otherwise keep outside the view.

[Public CVE record](https://www.cve.org/CVERecord?id=CVE-2026-40383) · [Vendor advisory or update instructions](https://developer.joomla.org/security-centre/1041-20260509-core-lfi-in-htmlview-layout-parameter.html) · [Module source](modules/CVE-2026-40383.rs) · [Source and API bundle](../../cve/CVE-2026-40383/README.md)

## Synthetic HTTP controls

**Tier 1 — declarative policy.** The recorded policy denies every method on the recorded fixture route and its descendants. This is a coarse rule: it also blocked the benign probe on the same route, which is the recorded false positive.

```json
{
  "version": 1,
  "profile": "http-structure-v1",
  "policy": {
    "version": 1,
    "rules": [
      {
        "scope": {
          "methods": [],
          "path": "/index.php",
          "descendants": true
        },
        "require": {
          "kind": "deny"
        }
      }
    ]
  }
}
```

**Tier 2 — native Rust module.** The rule checks a target containing layout= for selected traversal strings anywhere in that target.

```rust
static MARKS: [&[u8]; 5] = [b"../", b"..%2f", b"%2e%2e", b"/etc/", b"file:"];
```

## Implement the remediation

**Vendor update.** In Joomla Administrator, install the supported Joomla CMS release containing the fix through Joomla Update. Joomla lists 5.4.6 and 6.1.1 as fixed releases. [Vendor instructions](https://developer.joomla.org/security-centre/1041-20260509-core-lfi-in-htmlview-layout-parameter.html).

The published package uses registry name `joomla-htmlview-layout-guard`. Verify its own archive digest before import. Use the [fixture API example](../../cve/CVE-2026-40383/http-request-filter/api.md) to reproduce the recorded comparison. It covers the declaration, signed module activation, verification, revocation, and restoration.

## Fixture and probes

The benign probe rendered an article with the standard blog layout. The marked probe requested a layout traversing to a system file. The fixture incremented its marker when a traversal-bearing layout reached the include path.

## Test scope

The rule checks a target containing layout= for selected traversal strings anywhere in that target. The fixture did not run Joomla’s layout resolver or include a file.

## Signed module authority

Import returned HTTP 201 with explicit activation required and signature verification deferred. Read-only inspection was refused (403) for the reader principal, admission of a tampered statement was rejected (400), and admission of an invalid signature was refused (403). The activation receipt reported the module serving on all 32 expected shards. After revocation the marked probe received HTTP 503 (fail-closed); re-approval and reactivation restored the refusal (403, counter unchanged).
