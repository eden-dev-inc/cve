# SeaDoc: absolute path traversal to RCE in the converter (CVE-2026-129167)

An unauthenticated attacker holding a public share token can make the SeaDoc converter extract an attacker-chosen ZIP into the Python library path and then trigger its import through a file-convert request, executing the attacker's module on the server. The converter trusts an absolute filename in the conversion request, so a public .sdoc or wiki link becomes remote code execution.

## The vulnerability

The confluence-to-wiki conversion accepts a filename from the request and extracts a downloaded archive without confining it to the conversion workspace, so an absolute path lands the archive in the Python library path and the next import executes it. Eden fronts the SeaDoc converter, so the traversal rides an HTTP request Eden can refuse before release.

## The Eden patch

**Tier 1 — declarative policy.** The recorded policy denies every method on `/api/v1/confluence-to-wiki` and its descendants. This is a coarse rule: it also blocked the benign conversion, which is the recorded false positive.

```json
{ "version": 1, "profile": "http-structure-v1", "policy": { "version": 1, "rules": [ { "scope": { "methods": [], "path": "/api/v1/confluence-to-wiki", "descendants": true }, "require": { "kind": "deny" } } ] } }
```

**Tier 2 — native Rust module.** `gabriel_seadoc_v1` waits for a complete request, matches targets starting with `/api/v1/confluence-to-wiki`, and refuses bodies carrying traversal markers (`..`, `file:`, percent-encoded forms) or a JSON path value starting at the filesystem root (`: "/`). Relative conversion paths continue.

```rust
const ROUTE: &[u8] = b"/api/v1/confluence-to-wiki";
static MARKS: [&[u8]; 3] = [b"..", b"file:", b"file%3a"];
// plus a byte scan refusing JSON values rooted at "/"
```

## Implement the remediation

The commands are operator examples for the recorded scope. Compare fixture routes and software selectors with the intended deployment before use. See [deployment prerequisites](../deployment.md) and the [API example](../../cve/CVE-2026-129167/http-request-filter/api.md).

1. **Prepare the target.** Verify the loaded Seafile SeaDoc version against the advisory. Use a compatible Eden HTTP interlay and an authenticated operator with Configure permission. Use the recorded declaration and the linked source.
2. **Apply the declarative policy.** Set `INTERLAY` to the target interlay UUID in the authenticated Eden CLI. Save the interlay's complete current settings, place the policy from this report in `settings.remediation`, and PATCH the full settings object with a fresh `Idempotency-Key`. Read the interlay back and confirm `remediation_status.state` is `ready`.
3. **Import and activate the native module.** Build the schema-2 archive from the linked source with the compatible SDK, verify its digest, and PUT it to the interlay's patch-packages endpoint. Import requires explicit activation: enroll the publisher key, attest the host inventory, inspect the returned configuration, obtain independent host approval, sign the typed statement, admit, and activate. Read the receipt until `serving_now` is true and the expected shards are acknowledged. Full command sequences are in the [API example](../../cve/CVE-2026-129167/http-request-filter/api.md).
4. **Verify, revoke, and restore.** Replay the benign and advisory-shaped probes and compare the backend counter. Revoke the operation and confirm the marked fixture request no longer succeeds (fail-closed 503); re-approve, re-admit, and reactivate a replacement operation to restore protection.

**Vendor update.** Apply the fix for the installed release line and verify the application behavior after upgrading. [Advisory reference](https://vul.yulun.ac.cn/20261024/seafile/)

## Fixture and probes

The benign probe converted a shared document by its relative path (`doc.sdoc`). The marked fixture probe supplied an absolute extraction path (`/usr/lib/python3/dist-packages/pwn.py`). The fixture incremented its marker when the archive landed outside the workspace.

## Measured comparison (2026-11-13 UTC)

The values after each status are the observed increases in the fixture's effect counter.

| Benign relative conversion | 200, 0 | 403, 0 | 200, 0 |

The byte scan refuses traversal markers and root-absolute JSON path values; URL forms that decode only inside the converter (double-encoded, mixed separators) were not exercised. The advisory assumes a public share token; anonymous conversions were not tested.

Read-only inspection was refused (403) for the reader principal, admission of a tampered statement was rejected (400), and admission of an invalid signature was refused (403). ## Test scope

The fixture refused a root-absolute path on the converter route. The archive extraction and follow-on Python import were outside the fixture. Coverage is limited to the path shapes the rule recognizes.
