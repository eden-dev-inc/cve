# Cloud Storage Manager for Fluent Forms: unauthenticated path traversal write (CVE-2026-120522)

A remote caller can exploit missing authorization and filename handling in the WordPress Cloud Storage Manager plugin to write files on the server. A successful attack can alter site files and compromise the installation.

## The vulnerability

The affected versions and upgrade guidance are listed above. The Eden policy and module were tested against the HTTP fixture described below.

## Synthetic HTTP controls

**Tier 1 — declarative policy.** The recorded policy denies every method on the recorded fixture route and its descendants. This is a coarse rule: it also blocked the benign probe on the same route, which is the recorded false positive.

```json
{
  "version": 1,
  "profile": "http-structure-v1",
  "policy": {
    "version": 1,
    "rules": [
      {
        "scope": {
          "methods": [],
          "path": "/wp-json/csm",
          "descendants": true
        },
        "require": {
          "kind": "deny"
        }
      }
    ]
  }
}
```

**Tier 2 — native Rust module.** The rule scans synthetic WordPress REST requests for selected path strings.

```rust
const ROUTE: &[u8] = b"/wp-json/";
static MARKS: [&[u8]; 5] = [b"../", b"..%2f", b"%2e%2e", b"/etc/", b"file:"];
```

## Test scope

The fixture scans /wp-json/ requests for selected path strings. It did not save credentials, invoke Google Drive, read a filename returned by Google Drive, or write a file. The vendor vulnerability depends on metadata received from the storage provider.
