# JCE: unauthenticated PHP upload to server takeover (CVE-2026-48907)

An unauthenticated attacker can create an editor profile in JCE that permits executable uploads. They can then upload and run PHP code on the Joomla server.

**Patch title.** JCE Executable Upload Guard (`jce-executable-upload-guard` in the registry). The [original source snapshot](https://github.com/eden-dev-inc/cve/blob/9a7217a0a882374c5ab97d74c96df9b77637f923/docs/case-studies/modules/CVE-2026-48907.rs) preserves the source available for the historical report.

## Synthetic HTTP controls

**Tier 1 — declarative policy.** The recorded policy denies every method on the recorded fixture route and its descendants. This is a coarse rule: it also blocked the benign probe on the same route, which is the recorded false positive.

```json
{
  "version": 1,
  "profile": "http-structure-v1",
  "policy": {
    "version": 1,
    "rules": [
      {
        "scope": {
          "methods": [],
          "path": "/jce",
          "descendants": true
        },
        "require": {
          "kind": "deny"
        }
      }
    ]
  }
}
```

**Tier 2 — native Rust module.** The shared rule scans the target and body for .php or phar: when the target contains jce, pagebuilder, or balbooa.

```rust
static MARKS: [&[u8]; 2] = [b".php", b"phar:"];
```

## Implement the remediation

**Vendor update.** Update JCE to 2.9.99.5 or a later supported release. Follow the vendor’s guidance to check for unexpected profiles and uploads on sites that ran an affected version. [Vendor instructions](https://www.joomlacontenteditor.net/news/jce-security-update-and-a-free-patch-for-older-sites).

The published package uses registry name `jce-executable-upload-guard`. Verify its own archive digest before import. Use the [fixture API example](../../cve/CVE-2026-48907/http-request-filter/api.md) to reproduce the recorded comparison. It covers the declaration, signed module activation, verification, revocation, and restoration.

## Fixture and probes

The benign probe uploaded a document attachment. The marked probe uploaded shell.php. The fixture incremented its marker when a PHP-named upload reached the handler.

## Test scope

The shared rule scans the target and body for .php or phar: when the target contains jce, pagebuilder, or balbooa. The fixture did not create a JCE editor profile, write an uploaded file, or execute PHP.

## Signed module authority

Import returned HTTP 201 with explicit activation required and signature verification deferred. Read-only inspection was refused (403) for the reader principal, admission of a tampered statement was rejected (400), and admission of an invalid signature was refused (403). The activation receipt reported the module serving on all 32 expected shards. After revocation the marked probe received HTTP 503 (fail-closed); re-approval and reactivation restored the refusal (403, counter unchanged).
