# Kendo UI for jQuery: XSS in Form item hints (CVE-2026-124695)

[CVE advisory record](https://cve.now/CVE-2026-124695) · [Vendor advisory](https://www.telerik.com/kendo-jquery-ui/documentation/knowledge-base/kb-security-kendo-form-item-hint-xss-cve-2026-124695) · [Module source](modules/gabriel_kendoform_v1.rs)

**Result.** The marked request reached the backend in the baseline and raised its counter. The native rule refused that request with HTTP 403 and preserved HTTP 200 for the benign probe. The synthetic fixture ran through Eden 1.103.0 on November 12, 2026 (UTC).

## The vulnerability

Kendo Form accepts a hint string on each item. The affected renderer treats that string as HTML. When a form configuration takes hints from user-controlled content, viewing the form can cause active markup to run in the application’s origin.

Progress lists affected builds from 2020.2.513 through 2026.3.1015. The fix is in 2026.4.1111. The CVE record reports a CVSS base score of **7.1**.

## The Eden patch

**Tier 1 — declarative policy.** The recorded policy denies requests to `/kendo-ui/form` and its descendants. The empty method list leaves the deny unrestricted by HTTP method. This is a coarse rule and blocked the benign probe on the same path.

```json
{
  "version": 1,
  "profile": "http-structure-v1",
  "policy": {
    "version": 1,
    "rules": [
      {
        "scope": {
          "methods": [],
          "path": "/kendo-ui/form",
          "descendants": true
        },
        "require": {
          "kind": "deny"
        }
      }
    ]
  }
}
```

**Tier 2 — native Rust module.** `gabriel_kendoform_v1` waits for the request to be complete, checks whether the request target starts with `/kendo-ui/form`, and looks for any configured marker in the body. The substring comparison is ASCII case-insensitive. Outside that prefix or without a marker, the module returns `Continue`. The shown lines are excerpts from the linked source.

```rust
const ROUTE: &[u8] = b"/kendo-ui/form";
static NEEDLES: [&[u8]; 2] = [b"<script", b"onerror="];
```

```rust
NEEDLES.iter().any(|n| find_ignore_case(body, n).is_some()) && return Ok(Decision::Refuse);
```

## Fixture and probes

The fixture was a synthetic HTTP handler behind Eden. It answered the probes and kept a separate counter that increased when the handler recognized its marker bytes. The counter measures a fixture effect. An HTTP 200 from the baseline does not by itself establish that the counter moved.

**Request.** `POST /kendo-ui/form/hint` for the benign probe and the marked probe.

The benign body contained a plain hint string. The attack probe placed a script marker in the hint and included an event-handler marker. The fixture recorded that the marked body arrived.

## Test scope

The filter operates on raw bytes and does not check the items array or the hint key. The observed refusal applies to the tested HTTP delivery path. Browser-generated hints, configurations assembled from another data source, and other HTML contexts were outside the run.
