# Ivanti Connect Secure: predictable-filename upload to a known location (CVE-2026-118527)

Ivanti Connect Secure's predictable filenames let a remote authenticated attacker with low privileges upload content they control to a known location on disk — and attacks using the flaw are happening, per its CISA KEV listing. A VPN appliance with a planted file at a known path is a staging ground for full compromise.

## The vulnerability

The appliance resolves upload destinations with predictable names, so an attacker plants content at a known path with controlled bytes. Eden fronts the appliance's web interface, so the crafted upload rides an HTTP request Eden can refuse before release.

## The Eden patch

**Tier 1 — declarative policy.** The recorded policy denies every method on the recorded fixture route and its descendants. This is a coarse rule: it also blocked the benign probe on the same route, which is the recorded false positive.

```json
{
  "version": 1,
  "profile": "http-structure-v1",
  "policy": {
    "version": 1,
    "rules": [
      {
        "scope": {
          "methods": [],
          "path": "/dana/web/upload",
          "descendants": true
        },
        "require": {
          "kind": "deny"
        }
      }
    ]
  }
}
```

**Tier 2 — native Rust module.** gabriel_icsupload_v1 waits for a complete request, matches Ivanti upload routes (/dana/), and refuses upload bodies whose filename parameter names a traversal or known predictable location (../, /tmp/, home/.) — the predictable-path shapes the flaw accepts.

```rust
const ROUTE: &[u8] = b"/dana/";
static MARKS: [&[u8]; 3] = [b"../", b"/tmp/", b"home/."];
```

## Implement the remediation

The commands are operator examples for the recorded scope. Compare fixture routes and software selectors with the intended deployment before use. See [deployment prerequisites](../deployment.md) and the [API example](../../cve/CVE-2026-118527/http-request-filter/api.md).

1. **Prepare the target.** Verify the loaded Ivanti Connect Secure version against the advisory. Use a compatible Eden HTTP interlay and an authenticated operator with Configure permission. Use the recorded declaration and the linked source.
2. **Apply the declaratory policy.** Set `INTERLAY` to the target interlay UUID in the authenticated Eden CLI. Save the interlay's complete current settings, place the policy from this report in `settings.remediation`, and PATCH the full settings object with a fresh `Idempotency-Key`. Read the interlay back and confirm `remediation_status.state` is `ready`.
3. **Import and activate the native module.** Build the schema-2 archive from the linked source with the compatible SDK, verify its digest, and PUT it to the interlay's patch-packages endpoint. Import requires explicit activation: enroll the publisher key, attest the host inventory, inspect the returned configuration, obtain independent host approval, sign the typed statement, admit, and activate. Read the receipt until `serving_now` is true and the expected shards are acknowledged. Full command sequences are in the [API example](../../cve/CVE-2026-118527/http-request-filter/api.md).
4. **Verify, revoke, and restore.** Replay the benign and advisory-shaped probes and compare the backend counter. Revoke the operation and confirm the advisory-shaped request no longer succeeds (fail-closed 503); re-approve, re-admit, and reactivate a replacement operation to restore protection.

**Vendor update.** The fixed release carries the durable repair; the [advisory](https://cve.now/CVE-2026-118527) links the vendor's update instructions where available. Eden's tiers are an enforcement stopgap for a deployment that cannot upgrade immediately.

## Fixture and probes

The benign probe uploaded a file under its ordinary name. The advisory-shaped probe named a traversal-marked predictable location. The fixture incremented its marker when an escaped destination reached its write handler.

## Measured comparison (2026-11-13 UTC)

The values after each status are the observed increases in the fixture's effect counter.

| Probe | Baseline | Declarative policy | Native module |
| --- | --- | --- | --- |
| Benign ordinary upload | 200, 0 | 403, 0 | 200, 0 |
| Advisory-shaped predictable-path upload | 200, 1 | 403, 0 | 403, 0 |

The rule matches traversal and known-location markers in upload filenames; the vendor's exact predictable names are version-specific, so operators should extend the marker set with the advisory's paths for their version. The durable fix is 25.1.1.3 / 22.8R2.6.
