# Paperclip: unauthenticated RCE via import payload (CVE-2026-41679)

Paperclip — a Node.js server and React UI orchestrating AI agent teams — is vulnerable to unauthenticated RCE prior to 2026.416.0: an attacker imports a crafted payload that the server executes. No login is needed for host compromise.

## The vulnerability

The import handling executes attacker-supplied payloads without authentication, so an unauthenticated caller runs code on the host. Eden fronts the Paperclip server, so the crafted import rides an HTTP request Eden can refuse before release.

## The Eden patch

**Tier 1 — declarative policy.** The recorded policy denies every method on the recorded fixture route and its descendants. This is a coarse rule: it also blocked the benign probe on the same route, which is the recorded false positive.

```json
{
  "version": 1,
  "profile": "http-structure-v1",
  "policy": {
    "version": 1,
    "rules": [
      {
        "scope": {
          "methods": [],
          "path": "/api",
          "descendants": true
        },
        "require": {
          "kind": "deny"
        }
      }
    ]
  }
}
```

**Tier 2 — native Rust module.** gabriel_paperclip_v1 waits for a complete request, matches API routes, and refuses import declarations carrying command or URL payloads (import + cmd / import + http) — the crafted-import shapes that reach the server runtime. Ordinary API calls continue.

```rust
const ROUTE: &[u8] = b"/api/";
```

## Implement the remediation

The commands are operator examples for the recorded scope. Compare fixture routes and software selectors with the intended deployment before use. See [deployment prerequisites](../deployment.md) and the [API example](../../cve/CVE-2026-41679/http-request-filter/api.md).

1. **Prepare the target.** Verify the loaded Paperclip (AI agent server) version against the advisory. Use a compatible Eden HTTP interlay and an authenticated operator with Configure permission. Use the recorded declaration and the linked source.
2. **Apply the declaratory policy.** Set `INTERLAY` to the target interlay UUID in the authenticated Eden CLI. Save the interlay's complete current settings, place the policy from this report in `settings.remediation`, and PATCH the full settings object with a fresh `Idempotency-Key`. Read the interlay back and confirm `remediation_status.state` is `ready`.
3. **Import and activate the native module.** Build the schema-2 archive from the linked source with the compatible SDK, verify its digest, and PUT it to the interlay's patch-packages endpoint. Import requires explicit activation: enroll the publisher key, attest the host inventory, inspect the returned configuration, obtain independent host approval, sign the typed statement, admit, and activate. Read the receipt until `serving_now` is true and the expected shards are acknowledged. Full command sequences are in the [API example](../../cve/CVE-2026-41679/http-request-filter/api.md).
4. **Verify, revoke, and restore.** Replay the benign and advisory-shaped probes and compare the backend counter. Revoke the operation and confirm the advisory-shaped request no longer succeeds (fail-closed 503); re-approve, re-admit, and reactivate a replacement operation to restore protection.

**Vendor update.** The fixed release carries the durable repair; the [advisory](https://cve.now/CVE-2026-41679) links the vendor's update instructions where available. Eden's tiers are an enforcement stopgap for a deployment that cannot upgrade immediately.

## Fixture and probes

The benign probe posted an ordinary upload. The advisory-shaped probe posted an import carrying a command and URL payload. The fixture incremented its marker when a crafted import reached the execution path.

## Measured comparison (2026-11-14 UTC)

The values after each status are the observed increases in the fixture's effect counter.

| Probe | Baseline | Declarative policy | Native module |
| --- | --- | --- | --- |
| Benign ordinary upload | 200, 0 | 403, 0 | 200, 0 |
| Advisory-shaped import RCE | 200, 1 | 403, 0 | 403, 0 |

The rule matches import declarations carrying cmd or http markers on API routes; payload encodings without these markers were not exercised and are a bypass to record. The durable fix is the vendor's 2026.416.0 patch.

## Signed module authority

Import returned HTTP 201 with explicit activation required and signature verification deferred. Read-only inspection was refused (403) for the reader principal, admission of a tampered statement was rejected (400), and admission of an invalid signature was refused (403). After revocation the advisory-shaped probe received HTTP 503 (fail-closed); re-approval and reactivation restored the refusal (403, counter unchanged).
