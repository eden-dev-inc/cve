# ASUS RT-AX55: authenticated command injection via start_apply (CVE-2023-39780)

An authenticated attacker on an ASUS RT-AX55 router can inject operating-system commands through the /start_apply.htm endpoint — the qos_bw_rulelist parameter accepts shell metacharacters that run with the router's privileges. On a consumer router that is a full device takeover; combined with default or reused credentials it is remotely critical.

**Result.** The injected field raised the backend counter in the baseline (200, +1). The declarative tier refused it (403, benign false positive recorded). The native module refused the injected apply (403, counter unchanged) while the benign apply stayed HTTP 200. Recorded through Eden 1.103.0 on 2026-11-13 (UTC).

## The vulnerability

The router's apply form interpolates a caller-supplied field into a shell command, so metacharacters append attacker commands under the router's privileges. Eden fronts the router's administration interface, so the injected apply rides an HTTP request Eden can refuse before release.

## The Eden patch

**Tier 1 — declarative policy.** The recorded policy denies every method on /start_apply.htm and its descendants. This blocks every configuration apply, benign or not (the recorded false positive).

```json
{
  "version": 1,
  "profile": "http-structure-v1",
  "policy": {
    "version": 1,
    "rules": [
      {
        "scope": {
          "methods": [],
          "path": "/start_apply.htm",
          "descendants": true
        },
        "require": {
          "kind": "deny"
        }
      }
    ]
  }
}
```

**Tier 2 — native Rust module.** gabriel_asusrouter_v1 waits for a complete request, matches targets starting with /start_apply.htm, and refuses bodies carrying shell metacharacter markers (;, $(, backtick). Clean apply fields continue.

```rust
const ROUTE: &[u8] = b"/start_apply.htm";
static MARKS: [&[u8]; 3] = [b";", b"$(", b"`"];
```

## Implement the remediation

The commands are operator examples for the recorded scope. Compare fixture routes and software selectors with the intended deployment before use. See [deployment prerequisites](../deployment.md) and the [API example](../../cve/CVE-2023-39780/http-request-filter/api.md).

1. **Prepare the target.** Verify the loaded ASUS RT-AX55 version against the advisory. Use a compatible Eden HTTP interlay and an authenticated operator with Configure permission. Use the recorded declaration and the linked source.
2. **Apply the declarative policy.** Set `INTERLAY` to the target interlay UUID in the authenticated Eden CLI. Save the interlay's complete current settings, place the policy from this report in `settings.remediation`, and PATCH the full settings object with a fresh `Idempotency-Key`. Read the interlay back and confirm `remediation_status.state` is `ready`.
3. **Import and activate the native module.** Build the schema-2 archive from the linked source with the compatible SDK, verify its digest, and PUT it to the interlay's patch-packages endpoint. Import requires explicit activation: enroll the publisher key, attest the host inventory, inspect the returned configuration, obtain independent host approval, sign the typed statement, admit, and activate. Read the receipt until `serving_now` is true and the expected shards are acknowledged. Full command sequences are in the [API example](../../cve/CVE-2023-39780/http-request-filter/api.md).
4. **Verify, revoke, and restore.** Replay the benign and advisory-shaped probes and compare the backend counter. Revoke the operation and confirm the marked fixture request no longer succeeds (fail-closed 503); re-approve, re-admit, and reactivate a replacement operation to restore protection.

**Vendor update.** Check the advisory and the vendor's release channel for a fix. Restrict the affected feature's exposure while a fix is unavailable. [Advisory reference](https://github.com/D2y6p/CVE/blob/main/asus/CVE-2023-39780/1/EN.md)

## Fixture and probes

The benign probe posted an ordinary apply field (a log-type change with the reboot flag). The marked fixture probe appended a shell command to the field. The fixture incremented its marker when injected commands reached its shell.
