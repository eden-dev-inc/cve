# RepoManager Logfile Path Traversal (CVE-2026-130159)

An authenticated (or, for the Paymenter case, unauthenticated) remote caller can submit the vendor-documented crafted parameter to a repomanager 5.13.2 deployment and reach command execution or arbitrary file read. Update to the vendor's fixed release.

**Result.** The vendor-documented attack shape reached the fixture's simulated sink on every attack probe in the baseline, and the native module refused each one with HTTP 403 before release — no crafted parameter reached the sink while the module served — while every benign probe kept HTTP 200, including the same-route other-action controls that must keep passing. After revocation the interlay failed closed rather than silently re-exposing the route, and a replacement operation restored the refusal.

## The vulnerability

RepoManager through 5.13.2 (fixed in 5.13.3): the `status/service` controller's
`get-unit-log` action passes the caller-supplied `logfile` POST parameter through
`Validate::string()` — HTML-escaping only — straight into a filesystem path
concatenation (`SERVICE_LOGS_DIR . '/' . $logDir . '/' . $logfile`) with no
`basename()`/`realpath()` containment check, so any authenticated user can read
arbitrary files readable by the web user (the vendor PoC:
`&logfile=../../../../../../etc/passwd`) — configuration, source, and the GPG
signing-key passphrase alike. Fixed in 5.13.3, which applies `basename()`.

## The Eden patch

**Tier 1 — declarative policy.** The recorded policy denies `POST` on the `/ajax/controller.php` route family. This is a coarse rule: it also blocks the benign probes on the same route (recorded false positives).

```json
{
  "version": 1,
  "profile": "http-structure-v1",
  "policy": {
    "version": 1,
    "rules": [
      {
        "scope": {
          "methods": [
            "POST"
          ],
          "path": "/ajax/controller.php",
          "descendants": true
        },
        "require": {
          "kind": "deny"
        }
      }
    ]
  }
}
```

**Tier 2 — native Rust module.** Refuse get-unit-log `logfile` values carrying path traversal, absolute paths, or nul bytes (the vendor poc shape). Detection is scoped to the vendor-documented vulnerable controller/action pair (the `controller=`/`action=` gates), so other actions on the same route keep passing — verified by the same-route control probes.

```rust
fn value_is_attack(raw: &[u8]) -> bool {
    let mut buf = [0u8; 256];
    let n = decoded(raw, &mut buf);
    let v = &buf[..n];
    if n == 0 {
        return false;
    }
    if v[0] == b'/' || v[0] == 0x00 {
        return true; // absolute path or NUL
    }
    // any ../ or ..\ traversal sequence (interior matches included)
    let mut i = 0usize;
    while i + 2 < n {
        if v[i] == b'.' && v[i + 1] == b'.' && (v[i + 2] == b'/' || v[i + 2] == b'\\') {
            return true;
        }
        i += 1;
    }
    // trailing ".." also escapes a directory
    if n >= 2 && v[n - 1] == b'.' && v[n - 2] == b'.' && (n == 2 || v[n - 3] == b'/' || v[n - 3] == b'\\') {
        return true;
    }
    false
}

/// Find the raw (urlencoded) value bytes of a form key in a urlencoded
/// body/query, starting the scan at `from`. Returns (start, end) of the
/// value slice. Advances the cursor past the terminating `&`.
fn find_value(src: &[u8], key: &[u8], from: usize) -> Option<(usize, usize)> {
    let n = src.len();
    let mut i = from;
    while i + key.len() <= n {
        let edge = i == 0 || src[i - 1] == b'&' || src[i - 1] == b'?';
        let eq = edge && {
            let mut m = true;
            for (j, kb) in key.iter().enumerate() {
                if lower(src[i + j]) != lower(*kb) {
                    m = false;
                    break;
                }
            }
            m
        };
        if eq {
            let start = i + key.len();
            let mut end = start;
            while end < n && src[end] != b'&' && src[end] != b' '
                && src[end] != b'\r' && src[end] != b'\n' {
                end += 1;
            }
            return Some((start, end));
        }
        i += 1;
    }
    None
}

fn request_is_attack(head: &[u8], body: &[u8]) -> bool {
    // The request line: METHOD /ajax/controller.php?... HTTP/x
    let line_end = head.iter().position(|&b| b == b'\r').unwrap_or(head.len());
    let reqline = &head[..line_end];
    let sp = reqline.iter().position(|&b| b == b' ').unwrap_or(0);
    if !starts_with_ci(&reqline[sp + 1..], ROUTE) {
        return false;
    }
    // controller + action gates: decode each raw value into a local
    // buffer (borrow-free) and compare case-insensitively
    if !form_value_equals(head, b"controller=", CONTROLLER)
        && !form_value_equals(body, b"controller=", CONTROLLER) {
        return false;
    }
    if !form_value_equals(head, b"action=", ACTION)
        && !form_value_equals(body, b"action=", ACTION) {
        return false;
    }
    // the logfile parameter must not carry traversal material
    match find_value(body, b"logfile=", 0)
        .or_else(|| find_value(head, b"logfile=", 0)) {
        Some((s, e)) => value_is_attack(&body[s..e]),
        None => false,
    }
}

fn find_value_literal(src: &[u8], key: &[u8], from: usize) -> Option<(usize, usize)> {
    let n = src.len();
    let mut i = from;
    while i + key.len() <= n {
        let edge = i == 0 || src[i - 1] == b'&' || src[i - 1] == b'?';
        if edge && &src[i..i + key.len()] == key {
            let start = i + key.len();
            let mut end = start;
            while end < n && src[end] != b'&' && src[end] != b' '
                && src[end] != b'\r' && src[end] != b'\n' {
                end += 1;
            }
            return Some((start, end));
        }
        i += 1;
    }
    None
}

/// Percent-decode one form value (in a local buffer) and compare it
/// case-insensitively against the expected value. Borrow-free by design.
fn form_value_equals(src: &[u8], key: &[u8], expect: &[u8]) -> bool {
    match find_value(src, key, 0) {
        Some((s, e)) => {
            let mut buf = [0u8; 64];
            let n = decoded(&src[s..e], &mut buf);
            eq_ci(&buf[..n], expect)
        }
        None => false,
    }
}

fn eq_ci(a: &[u8], b: &[u8]) -> bool {
    if a.len() != b.len() { return false; }
    a.iter().zip(b).all(|(x, y)| lower(*x) == lower(*y))
}
```

**Stated limits.** `logfile` values carrying benign punctuation still pass the byte scan (no
shell metacharacter scan — the sink is `file_get_contents`); a deployment whose
log names feed a shell command must additionally deploy the 5.13.3 command-layer
escaping. Durable fix: RepoManager 5.13.3.

## Signed module authority

Import returned HTTP 201 with explicit activation required and signature verification deferred. Read-only inspection was refused (403) for the reader principal, admission of a tampered statement was rejected (400), and admission of an invalid signature was refused (403). The activation receipt reported the module serving on all 32 expected shards. After revocation the marked probe received HTTP 503 (fail-closed); re-approval and reactivation restored the refusal.
