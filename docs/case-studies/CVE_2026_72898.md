# Metabase: SQL injection through password reset (CVE-2026-72898)

[Advisory record](https://cve.now/CVE-2026-72898) · [Vendor advisory](https://github.com/metabase/metabase/security/advisories/GHSA-vwf4-m7j8-wcjf)

**Status.** Two-tier request-filter comparison against Eden 1.103.0 using a synthetic HTTP fixture.

[Module source](modules/gabriel_metabasereset_v1.rs)

## The vulnerability

Metabase describes unauthenticated SQL injection in the password reset endpoint that can grant administrative access. The advisory lists fixed releases by series.

## The Eden patch

**Tier 1 — declarative policy.** Deny all requests under the fixture prefix `/api/session`, including benign requests.

**Tier 2 — native Rust module.** Match `/api/session/reset_password` and refuse requests containing a configured marker in the body.

## Measured comparison (2026-11-12 UTC)

| Configuration | Benign request | Attack fixture |
| --- | --- | --- |
| Baseline | HTTP 200 | HTTP 200, backend marker recorded |
| Tier 1 route deny | HTTP 403 | HTTP 403 |
| Tier 2 native module | HTTP 200 | HTTP 403, backend marker absent |

## Signed module authority

The module was imported for explicit activation. All expected shards acknowledged activation. Reader inspection, a tampered statement and an invalid signature were rejected. After revocation the same request received HTTP 503. Re-approval and reactivation restored HTTP 403.

## Test scope

The fixture tests SQL markers in HTTP bodies on the password-reset route. Database query execution and acquisition of administrator access remain unverified.

The measurements cover the supplied fixture probes. Alternate routes, encodings, and other bypasses remain untested.
