# Cisco Secure Email Gateway: SQL injection during email parsing (CVE-2026-76461)

[CVE advisory record](https://cve.now/CVE-2026-76461) · [Vendor advisory](https://sec.cloudapps.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-esa-inj-2bLVGmhX) · [Module source](modules/gabriel_ciscoemailsqli_v1.rs)

**Result.** The marked request reached the backend in the baseline and raised its counter. The native rule refused that request with HTTP 403 and preserved HTTP 200 for the benign probe. The synthetic fixture ran through Eden 1.103.0 on November 12, 2026 (UTC).

## The vulnerability

Cisco traces the vulnerability to AsyncOS email parsing. Crafted content delivered as an email can enter a SQL operation and, on affected systems, result in operating-system command execution with root privileges. The delivery mechanism is the processing of a message by the gateway.

Cisco lists patched AsyncOS builds by release train, including 15.5.5-014, 16.0.4-302, and 16.5.0-780. The CVE record reports a CVSS base score of **9.8**.

## The Eden patch

**Tier 1 — declarative policy.** The recorded policy denies requests to `/api/emails` and its descendants. The empty method list leaves the deny unrestricted by HTTP method. This is a coarse rule and blocked the benign probe on the same path.

```json
{
  "version": 1,
  "profile": "http-structure-v1",
  "policy": {
    "version": 1,
    "rules": [
      {
        "scope": {
          "methods": [],
          "path": "/api/emails",
          "descendants": true
        },
        "require": {
          "kind": "deny"
        }
      }
    ]
  }
}
```

**Tier 2 — native Rust module.** `gabriel_ciscoemailsqli_v1` waits for the request to be complete, checks whether the request target starts with `/api/emails/search`, and looks for any configured marker in the body. The substring comparison is ASCII case-insensitive. Outside that prefix or without a marker, the module returns `Continue`. The shown lines are excerpts from the linked source.

```rust
const ROUTE: &[u8] = b"/api/emails/search";
static NEEDLES: [&[u8]; 3] = [b"' OR ", b"union select", b"1=1"];
```

```rust
NEEDLES.iter().any(|n| find_ignore_case(body, n).is_some()) && return Ok(Decision::Refuse);
```

## Fixture and probes

The fixture was a synthetic HTTP handler behind Eden. It answered the probes and kept a separate counter that increased when the handler recognized its marker bytes. The counter measures a fixture effect. An HTTP 200 from the baseline does not by itself establish that the counter moved.

**Request.** `POST /api/emails/search` for the benign probe and the marked probe.

The fixture sent an ordinary sender search and a SQL predicate in the query field of a synthetic HTTP search. The unfiltered handler recorded the marked HTTP body.

## Test scope

The report demonstrates an HTTP request filter on a synthetic search route. Cisco's advisory describes crafted email delivery and parsing, which remain outside this module's tested scope. In particular, an SMTP message does not pass through this HTTP body matcher.
