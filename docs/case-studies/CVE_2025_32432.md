# Craft CMS: unauthenticated remote code execution (CVE-2025-32432)

An unauthenticated caller can run code of their choosing on a Craft CMS server through a crafted action parameter, compromising the site's confidentiality, integrity and availability. The advisory notes active exploitation, so an exposed install should be treated as compromised.

**Result.** The advisory-shaped action raised the backend counter in the baseline (200, +1). The declarative tier refused it (403, benign false positive recorded). The native module refused the advisory-shaped action (403, counter unchanged) while the benign action stayed HTTP 200. Recorded through Eden 1.103.0 on 2026-11-13 (UTC).

## The vulnerability

Craft's action dispatch evaluates a crafted parameter as code under the server's privileges, reachable unauthenticated. Eden fronts the CMS web tier, so the crafted action rides an HTTP request Eden can refuse before release.

## The Eden patch

**Tier 1 — declarative policy.** The recorded policy denies every method on /index.php and its descendants. This is the bluntest tier: it blocks the whole CMS entrypoint (the recorded false positive) and is an emergency posture only.

```json
{
  "version": 1,
  "profile": "http-structure-v1",
  "policy": {
    "version": 1,
    "rules": [
      {
        "scope": {
          "methods": [],
          "path": "/index.php",
          "descendants": true
        },
        "require": {
          "kind": "deny"
        }
      }
    ]
  }
}
```

**Tier 2 — native Rust module.** gabriel_craftcms_v1 waits for a complete request, matches POSTs to /index.php, and refuses an action-bearing body carrying eval-injection markers (eval(, assert(, system(). Action bodies without those markers continue.

```rust
static NEEDLES: [&[u8]; 3] = [b"eval(", b"assert(", b"system("];
```

## Implement the remediation

The commands are operator examples for the recorded scope. Compare fixture routes and software selectors with the intended deployment before use. See [deployment prerequisites](../deployment.md) and the [API example](../../cve/CVE-2025-32432/http-request-filter/api.md).

1. **Prepare the target.** Verify the loaded Craft CMS version against the advisory. Use a compatible Eden HTTP interlay and an authenticated operator with Configure permission. Use the recorded declaration and the linked source.
2. **Apply the declarative policy.** Set `INTERLAY` to the target interlay UUID in the authenticated Eden CLI. Save the interlay's complete current settings, place the policy from this report in `settings.remediation`, and PATCH the full settings object with a fresh `Idempotency-Key`. Read the interlay back and confirm `remediation_status.state` is `ready`.
3. **Import and activate the native module.** Build the schema-2 archive from the linked source with the compatible SDK, verify its digest, and PUT it to the interlay's patch-packages endpoint. Import requires explicit activation: enroll the publisher key, attest the host inventory, inspect the returned configuration, obtain independent host approval, sign the typed statement, admit, and activate. Read the receipt until `serving_now` is true and the expected shards are acknowledged. Full command sequences are in the [API example](../../cve/CVE-2025-32432/http-request-filter/api.md).
4. **Verify, revoke, and restore.** Replay the benign and advisory-shaped probes and compare the backend counter. Revoke the operation and confirm the marked fixture request no longer succeeds (fail-closed 503); re-approve, re-admit, and reactivate a replacement operation to restore protection.

**Vendor update.** Apply the fix for the installed release line and verify the application behavior after upgrading. [Advisory reference](https://github.com/craftcms/cms/security/advisories/GHSA-f3gw-9ww9-jmc3)

## Fixture and probes

The benign probe posted an ordinary save action. The marked fixture probe posted an action body carrying eval(base64_decode(...)). The fixture incremented its marker when the injected expression reached its dispatch.

## Measured comparison (2026-11-13 UTC)

The values after each status are the observed increases in the fixture's effect counter.

| Probe | Baseline | Declarative policy | Native module |
| --- | --- | --- | --- |
| Benign save action | 200, 0 | 403, 0 | 200, 0 |
| Advisory-shaped eval action | 200, 1 | 403, 0 | 403, 0 |

The rule matches the recorded eval-injection markers on /index.php; alternate encodings or action names that avoid these bytes were not exercised.

## Signed module authority

Import returned HTTP 201 with explicit activation required and signature verification deferred. Read-only inspection was refused (403) for the reader principal, admission of a tampered statement was rejected (400), and admission of an invalid signature was refused (403). The activation receipt reported the module serving on all 32 expected shards. After revocation the advisory-shaped probe received HTTP 503 (fail-closed); re-approval and reactivation restored the refusal.
